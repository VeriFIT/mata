Mata

A fast and simple library for finite automata, with interfaces in C++, Python and Rust.

Mata builds automata from regular expressions and from its own .mata format, then determinizes, minimizes, reduces and combines them, and decides emptiness, inclusion and equivalence. When the answer is no, it also gives you a word that shows why. Mata is the automata engine of the Z3-Noodler string solver.

What Mata does

Mata covers the automata operations that verification tools and string solvers rely on, with the algorithms that make them fast in practice: antichains for inclusion and universality, simulations for reduction, and a compact transition relation underneath.

Build
Create automata from regular expressions (parsed by RE2), from the textual .mata format, or transition by transition.
Transform
Determinize, minimize with Hopcroft’s or Brzozowski’s algorithm, reduce by simulation or to a residual automaton, trim, remove ε-transitions, reverse and complement.
Combine
Intersect automata with the product construction, unite and concatenate them, and compute language differences.
Decide
Check emptiness, universality, inclusion and equivalence. A negative answer comes with a word that witnesses it.
Solve string constraints
Split automata into segments at ε-transitions and enumerate their noodles, the decision procedure behind Z3-Noodler.
Transduce
Compose finite transducers, apply them to words and automata, and project out their tapes. Transducer support is experimental, and its interface may still change.

Get started

The same small program in each language: an automaton with four states, two of them initial and two final, printed in the DOT format.

Add Mata to your CMake project

Use an installed Mata, or let CMake fetch and build it. Mata needs CMake 3.23 and a C++23 compiler (GCC 14 or Clang 18). 

include(FetchContent)
find_package(mata QUIET)
if(NOT mata_FOUND)
  FetchContent_Declare(mata
    GIT_REPOSITORY https://github.com/VeriFIT/mata
    GIT_TAG devel)
  FetchContent_MakeAvailable(mata)
endif()
target_link_libraries(my-project PUBLIC mata::libmata)

Mata is also packaged for Nix: nix build nixpkgs#mata.

Write and run

#include <iostream>
#include <mata/nfa/nfa.hh>

using namespace mata::nfa;

int main() {
    Nfa aut(4);
    aut.initial = {0, 1};
    aut.final = {2, 3};
    aut.delta.add(0, 0, 2);
    aut.delta.add(1, 1, 3);

    aut.print_to_dot(std::cout);
}

Install the libmata package

The package is on PyPI and needs Python 3.13 or newer. Installing it compiles Mata, which needs CMake 3.23 and a C++23 compiler (GCC 14 or Clang 18). 

pip install libmata
# or, with uv:
uv add libmata

Write and run

import libmata.nfa.nfa as mata_nfa

aut = mata_nfa.Nfa(4)
aut.initial_states = {0, 1}
aut.final_states = {2, 3}
aut.add_transition(0, 0, 2)
aut.add_transition(1, 1, 3)

print(aut.to_dot_str())

Three Jupyter notebooks show larger uses: WS1S formulae, ReDoS attacks and a maze.

Add the mata crate

The crate needs Rust 1.88 or newer. Its companion crate mata-sys compiles Mata, which needs CMake 3.23 and a C++23 compiler (GCC 14 or Clang 18). 

cargo add mata

Write and run

use mata::{Error, Nfa, State, Symbol};

fn main() -> Result<(), Error> {
    let mut aut = Nfa::with_states(4);

    aut.add_initial(State::new(0))?;
    aut.add_initial(State::new(1))?;
    aut.add_final(State::new(2))?;
    aut.add_final(State::new(3))?;
    aut.add_transition(State::new(0), Symbol::new(0), State::new(2))?;
    aut.add_transition(State::new(1), Symbol::new(1), State::new(3))?;

    println!("{}", aut.dot());
    Ok(())
}

The API reference is on docs.rs.

Try it in your browser

The playground runs Mata compiled to WebAssembly. Enter regular expressions or automata in the .mata format, then determinize, minimize, intersect or compare them and see the results drawn as you type. Everything runs in your browser; nothing is uploaded.
