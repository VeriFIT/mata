Struct mata::utils::TwoDimensionalMap::SparseRow¶

struct SparseRow¶

The hash table of the second-dimension keys paired with one first-dimension key.

Public Types

using Counter = std::conditional_t<(sizeof(T) <= sizeof(uint32_t)), uint32_t, uint64_t>¶

Wide enough to count the keys of a row, which are distinct values of T: a row of 32-bit keys then takes two words.

Public Members

Counter size = {0}¶

Number of stored keys.

Counter shift = {0}¶

Bits of a 64-bit hash discarded to index the slots: 64 - log2 of the number of slots. Always 64, never Counter: capacity() must stay representable even when a row has Counter-many keys.
