Struct mata::nft::algorithms::CompositionSchedule¶

struct CompositionSchedule

The common level layout of the general composition of two NFTs.

The aligned levels come in blocks, one per synchronization level and one after the last: the levels only lhs reads, then the levels only rhs reads, then the synchronization level, which the last block lacks. The result of the composition has the aligned levels in this order, without the synchronization levels when they are projected out. Example: 

           LHS                         |                    RHS
—————————————–—+——————————————— num_of_levels = 5 | num_of_levels = 4 sync_levels = { 2, 4 } | sync_levels = { 1, 2 } —————————————–—+——————————————— positions: lhs 0, lhs 1, rhs 0, sync (2, 1), lhs 3, sync (4, 2), rhs 3 lhs_new_levels_mask() = { 0, 0, 1, 0, 0, 0, 1 }, rhs_new_levels_mask() = { 1, 1, 0, 0, 1, 0, 0 }

enum class Owner : uint8_t

Which operand reads an aligned level.

Values:

enumerator Lhs

Only lhs reads it; rhs is not inserted into it.

enumerator Rhs

Only rhs reads it.

enumerator Sync

Both read it: a synchronization level.
