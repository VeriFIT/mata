enum class DeterminizationReduction : std::uint8_t

Reduction of the DFA of determinize_four_russians() and determinize_classical() to a smaller DFA for the same language, not always minimal. There is no real winner, but based on benchmarks, Adaptive is the best choice for general use.

Values:

enumerator None

No reduction.

enumerator Bisimulation

Merge bisimilar states. Fast.

enumerator Simulation

Also use the simulation. Smaller DFAs, but memory quadratic in the number of states.

enumerator Adaptive

Start with Bisimulation, and switch to Simulation if the DFA turns out large.

Nfa determinize_four_russians(const Nfa &aut, const FourRussiansOptions &options = {}, std::unordered_map<StateSet, State> *subset_map = nullptr, std::optional<std::function<bool(const Nfa&, State, const StateSet&)>> macrostate_discover = std::nullopt, const utils::OrdVector<Symbol> *restrict_to_symbols = nullptr)

Determinize automaton by the “Four Russians” subset construction.

This is the “Four Russians” technique of Arlazarov, Dinic, Kronrod and Faradzev (1970), applied lazily.

Gives the DFA of determinize_classical() up to the numbering of the states, usually much faster on large automata. The default algorithm of determinize(). The NFA states are cut into blocks, and the post of each combination of states of a block is computed once, when it first occurs, and kept in a table. The post of a macrostate is then a union over its blocks instead of its states.

With a reduction, it gives a smaller DFA for the same language, not always minimal. A reduction usually lowers the memory usage. Its effect on the time varies: inputs whose DFA shrinks a lot are much faster, others may be slower.

const Nfa dfa = algorithms::determinize_four_russians(aut);
const Nfa smaller = algorithms::determinize_four_russians(aut, {.reduction = DeterminizationReduction::Adaptive});
Parameters:

  • aut – [in] Automaton to determinize.

  • options – [in] Block size and reduction.

  • subset_map – [out] Map that maps sets of states of input automaton to states of determinized automaton (with a reduction, merged states appear as one of them).

  • macrostate_discover – [in] Callback event handler for discovering a new macrostate for the first time, as in determinize(). Not allowed with a reduction.

  • restrict_to_symbols – [in] When not nullptr, determinize over these symbols only, as in determinize().

Throws:

std::invalid_argument – for an invalid block size, or for a reduction with macrostate_discover.

Returns:

Determinized automaton.

Nfa minimize_hopcroft(const Nfa &dfa_trimmed)

Hopcroft minimization of automata.

Based on the algorithm from the paper: “Efficient Minimization of DFAs With Partial Transition Functions” by Antti Valmari and Petri Lehtinen. The algorithm works in O(a*n*log(n)) time and O(m+n+a) space, where: n is the number of states, a is the size of the alphabet, and m is the number of transitions. [https://dl.acm.org/doi/10.1016/j.ipl.2011.12.004]

Parameters:

dfa_trimmed – [in] Deterministic automaton without useless states. Perform trimming before calling this function.

Returns:

Minimized deterministic automaton.

Nfa minimize_auto(const Nfa &aut)

Minimization that picks the algorithm from the shape of the input.

Determinizes aut when it is not deterministic already, trims it, and runs Hopcroft minimization on the result. Brzozowski minimization is never picked: it determinizes twice, so it can blow up exponentially even on an input that is already a trimmed DFA, where Hopcroft is O(a*n*log(n)). An automaton with an empty language is returned as a single non-final initial state with no transitions.

Parameters:

aut – [in] Automaton to be minimized.

Returns:

Minimal deterministic automaton.

std::vector<State> identical_successor_classes(const Automaton &aut, size_t num_of_states, std::span<const Level> levels = {})

Classes of states that have the same finality, the same level, and, over every symbol, successors in the same classes.

Starts from the identity and merges states with identical successors, then states whose successors became identical by the merge, until nothing merges. Every merge joins classes with the same successors, so the partition stays a bisimulation and the quotient keeps the forward simulation of every state. It is far cheaper than the simulation itself: the first pass hashes each state post once, and after it only the classes of the predecessors of the states of an absorbed class are hashed again. The classes are numbered in the order of their smallest states.

Parameters:

  • aut – [in] Automaton whose states to classify.

  • num_of_states – [in] Number of states of aut.

  • levels – [in] Level of each state of a transducer. States past its end, and all states of an NFA, for which it is empty, are on level 0.

Returns:

The class of each state; the number of classes is one past the largest class.

inline uint64_t macrostate_signature(const StateSet &macrostate)

Signature of a macrostate: the OR of 1 << (q % 64) over its states q.

A superset can only have more bits set, so a bit present in macrostate_signature(a) and absent from macrostate_signature(b) exhibits a state of a that is missing from b and proves a ⊄ b. The converse does not hold: states that are congruent modulo 64 share a bit, so equal signatures prove nothing. The filter therefore only ever rejects, which is what the antichain subsumption tests need to stay sound.

Nfa concatenate_eps(const Nfa &lhs, const Nfa &rhs, const Symbol &epsilon, bool use_epsilon = false, StateRenaming *lhs_state_renaming = nullptr, StateRenaming *rhs_state_renaming = nullptr)

Concatenate two NFAs.

Connects lhs and rhs by adding ε-transitions from each final state of lhs to each initial state of rhs. The ε is set to epsilon. If use_epsilon is false, remove_epsilon(epsilon) is run on the result, so every transition over epsilon disappears, including the operands’ own transitions labelled with that symbol. Operand transitions over any other symbol are preserved; in particular, with epsilon != EPSILON the operands’ EPSILON transitions survive, which is not the case when epsilon == EPSILON.

Parameters:

  • lhs – [in] First automaton to concatenate.

  • rhs – [in] Second automaton to concatenate.

  • epsilon – [in] Symbol used for the connecting transitions between lhs and rhs.

  • use_epsilon – [in] Whether to keep the connecting epsilon transitions in the result.

  • lhs_state_renaming – [out] Map mapping lhs states to result states.

  • rhs_state_renaming – [out] Map mapping rhs states to result states.

Returns:

Concatenated automaton.

Nfa concatenate_eps(Nfa &&lhs, const Nfa &rhs, const Symbol &epsilon, bool use_epsilon = false, StateRenaming *lhs_state_renaming = nullptr, StateRenaming *rhs_state_renaming = nullptr)

Concatenate two NFAs with epsilon transitions, consuming the left operand.

The left operand’s state posts are moved into the result. The right operand is copied normally. If lhs and rhs are aliased, a controlled snapshot of rhs is taken and the operation falls back to the lvalue path. lhs is left valid but empty after the operation.

Nfa concatenate_eps(Nfa &&lhs, Nfa &&rhs, const Symbol &epsilon, bool use_epsilon = false, StateRenaming *lhs_state_renaming = nullptr, StateRenaming *rhs_state_renaming = nullptr)

Concatenate two NFAs with epsilon transitions, consuming both operands.

The state posts of both operands are moved into the result. If lhs and rhs are aliased, a controlled snapshot of rhs is taken before lhs is consumed, so the result holds both copies. Both lhs and rhs are left valid but empty after the operation.

Nfa quotient_by_simulation(const Nfa &nfa, const Simlib::Util::BinaryRelation &sim_relation, const std::vector<size_t> &quot_proj, const BoolVector *states = nullptr, StateRenaming *state_renaming = nullptr)

Quotient an NFA, or a successor-closed part of it, by its forward simulation.

Each class of states equivalent under sim_relation becomes one state; its transitions are those of the class representative, without targets simulated by another target over the same symbol. With states set, only those states are kept and the representative of a class is its smallest kept state. Since forward simulation does not depend on the initial states, one relation then serves every part reachable from a single state.

Parameters:

  • nfa – [in] NFA to quotient.

  • sim_relation – [in] Forward simulation of nfa, as computed by compute_relation().

  • quot_proj – [in] Projection of each state of nfa to the smallest state of its class, as computed by get_symmetric_quotient_projection() of sim_relation.

  • states – [in] States to keep; all states if nullptr. Must be closed under successors.

  • state_renaming – [out] Map mapping the kept states to the reduced states, if not nullptr.

Returns:

The quotient of nfa restricted to states.

Nfa quotient_by_simulation(const Nfa &nfa, const Simlib::Util::PartitionRelation &sim_relation, const std::vector<size_t> &quot_proj, const BoolVector *states = nullptr, StateRenaming *state_renaming = nullptr)

Reduce NFA using residual construction.

The residual construction of the residual automaton and the removal of the covering states is done during the last determinization.

Nfa reduce_sat(const Nfa &nfa, const std::string &type = "nfa", const std::string &solver = "")

Reduce NFA to an automaton with the minimum number of states using an external SAT solver.

Experimental. A counterexample-guided search: for k = 1, 2, …, a SAT solver looks for an automaton with k states consistent with a set of sample words, the candidate is checked for equivalence with nfa, and a distinguishing word is added to the samples until the candidate is equivalent or no k-state automaton exists. The search is exponential in the worst case and is practical only for languages whose minimal automata have about ten states.

Epsilon transitions over EPSILON are removed first. The result uses the symbols and the alphabet of nfa.

Parameters:

  • nfa – [in] NFA to reduce.

  • type – [in] Kind of the resulting automaton (values: “nfa”, “dfa”):

    • ”nfa”: an NFA with the minimum number of states. It never has more states than nfa reduced by simulation.

    • ”dfa”: a deterministic (not necessarily complete) automaton with the minimum number of states.

  • solver – [in] Command running a SAT solver, as the solver’s executable followed by its arguments separated by spaces. Parts containing spaces can be enclosed in single or double quotes; the command is not interpreted by a shell otherwise. The solver is given a DIMACS CNF file as its last argument and has to print the result in the format of the SAT competitions, that is, an “s SATISFIABLE” or “s UNSATISFIABLE” line and the model on “v” lines. If empty, the value of the environment variable MATA_SAT_SOLVER is used and, if that is not set, the first of cadical, kissat, cryptominisat5 and picosat found in PATH.

Throws:

  • ExternalSolverNotFound – If no SAT solver can be found or run.

  • std::runtime_error – If the solver fails or its output cannot be understood.

Returns:

An automaton equivalent to nfa with the minimum number of states of the given type.

Nfa reduce_qbf(const Nfa &nfa, const std::string &solver = "")

Reduce NFA to an NFA with the minimum number of states using an external QBF solver.

Experimental. The same search as reduce_sat() with type “nfa”, but the sample words that the NFA has to reject are encoded with universally quantified runs instead of the reachable states of their prefixes.

Parameters:

  • nfa – [in] NFA to reduce.

  • solver – [in] Command running a QBF solver, given as for reduce_sat(). The solver is given a QDIMACS file as its last argument and has to print the result and the values of the outermost existential variables in the QDIMACS output format (“s cnf 1 …” or “s cnf 0 …” and “V” lines). If empty, the value of the environment variable MATA_QBF_SOLVER is used and, if that is not set, the first of depqbf and caqe found in PATH (run with --qdo, and DepQBF also with --no-dynamic-nenofex if it supports the option).

Throws:

  • ExternalSolverNotFound – If no QBF solver can be found or run.

  • std::runtime_error – If the solver fails or its output cannot be understood.

Returns:

An NFA equivalent to nfa with the minimum number of states.
