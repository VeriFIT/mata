Namespace mata::nft::plumbing¶

namespace plumbing

Simplified NFA API, used in binding to call NFA algorithms.

In particular, this mostly includes operations and checks, that do not return Automaton, but instead take resulting automaton as pointer (e.g. void f(Nft* result, const Nft& lhs, const Nft& rhs)).

Compute intersection of two NFTs.

Both automata can contain ε-transitions. Epsilons will be handled as alphabet symbols.

Transducers must share alphabets. //TODO: this is not implemented yet. Transducers must have equal values of num_of_levels.

Parameters:

  • res – [out] Resulting NFT as a product of NFTs lhs and rhs.

  • lhs – [in] First NFT to compute intersection for.

  • rhs – [in] Second NFT to compute intersection for.

  • prod_map – [out] Mapping of pairs of the original states (lhs_state, rhs_state) to new product states (not used internally, allocated only when !=nullptr, expensive).

  • jump_mode – [in] Specifies if the symbol on a jump transition (a transition with a length greater than 1) is interpreted as a sequence repeating the same symbol or as a single instance of the symbol followed by a sequence of DONT_CARE.

inline utils::LazyWordGenerator *get_words_lazy_ptr(const Nft &aut, const std::optional<size_t> max_length = std::nullopt, const JumpMode jump_mode = JumpMode::RepeatSymbol)

Same as Nft::get_words_lazy(), but as a free function returning a heap-allocated wrapper instead of a std::generator.

Exists for callers that cannot drive a C++23 coroutine directly — namely the Python bindings, generated by Cython, which has no notion of C++23 coroutines/sentinels. Prefer Nft::get_words_lazy() everywhere else.

Throws std::runtime_error when MATA_HAS_GENERATOR_SUPPORT is unset (i.e. the standard library does not implement std::generator — some, like Apple’s system libc++, do not, even under -std=c++23).

Parameters:

  • aut – Automaton whose language is enumerated.

  • max_length – Maximum length of words to be returned. Default: “no limit”; will keep yielding forever if the language is infinite.

  • jump_mode – Specifies how to interpret the jump transitions.

Returns:

A heap-allocated generator; the caller takes ownership and must delete it.
