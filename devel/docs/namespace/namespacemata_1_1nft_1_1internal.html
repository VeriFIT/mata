Functions

void validate_nft_levels(const Nft &nft, const char *operation)

Throw std::invalid_argument when the level metadata of nft is incomplete or out of range.

Operations that interpret transitions through the level vector (jump unwinding, inclusion, equivalence) must not silently treat a transducer with missing or malformed levels as a flat NFA; that produced wrong answers without any error (#791).

Parameters:

operation – Name of the operation, used in the exception message.

bool unwinding_changes(const Nft &nft, const utils::OrdVector<Symbol> &dont_care_symbol_replacements)

Whether unwinding nft with dont_care_symbol_replacements changes it: a transition does not advance exactly one level, or a DONT_CARE is spelled out (it is kept only when it is its own sole replacement).
