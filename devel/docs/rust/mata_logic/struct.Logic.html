Struct Logic

Builds formulas over variables from atoms given as automata, and decides them with mata_lazy.

An assignment is encoded as a word of columns, one bit per variable, read on one tape per variable in lock step. An atom is an Automaton over the bits ZERO and ONE that accepts exactly the encodings of the assignments that satisfy it, with every Padding. The connectives keep this invariant: the complement drops the words that encode nothing, and a quantifier closes the relation under padding after it drops a tape.

use mata_logic::{Logic, Padding, ZERO, ONE};
use mata_lazy::{Automaton, Options, Symbol};

/// `x = y` over natural numbers: both tapes read the same bits.
struct Equal;

impl Automaton for Equal {
    type State = ();

    fn arity(&self) -> usize { 2 }
    fn initial_states(&self) -> impl IntoIterator<Item = ()> { [()] }
    fn is_final(&self, (): ()) -> bool { true }
    fn for_each_move(&self, (): (), mut visit: impl FnMut(&[Symbol], ())) {
        visit(&[ZERO, ZERO], ());
        visit(&[ONE, ONE], ());
    }
}

let mut logic = Logic::new(Padding::Zero);
let (x, y) = (logic.var("x"), logic.var("y"));
let equal = logic.atom(&Equal, &[x, y])?;
// ∀x ∃y. x = y
let every = logic.exists(&equal, &[y])?;
let every = logic.forall(&every, &[x])?;
assert!(logic.counterexample(&every, &Options::new())?.is_none());

pub fn atom( &mut self, automaton: &impl Automaton, vars: &[Var], ) -> Result<Prop, Error>

An atom: the relation of automaton, whose tape i encodes vars[i].

The relation must hold exactly the encodings of the assignments that satisfy the atom, with every padding, and read only ZERO and ONE (and ANY, which ranges over them); the other connectives rely on it. An atom without variables is decided now: it is true if automaton accepts the empty word.

§Errors

AtomArity if automaton does not have one tape per variable, ForeignVar, RepeatedVar, or Lazy from Formula::leaf_over.
