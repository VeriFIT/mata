Module ws1s

WS1S, the weak monadic second-order logic of one successor: formulas over positions and finite sets of positions, parsed from a MONA-like syntax and decided by a Logic with Padding::Zero.

use mata_lazy::Options;
use mata_logic::ws1s::{Value, Ws1s};

let mut ws1s = Ws1s::new();
let phi = ws1s.parse("(x = y + 1 & y = z + 1) => x = z + 2")?;
assert!(ws1s.valid(&phi, &Options::new())?);

let psi = ws1s.parse("x in X & 3 < x & all1 y: y in X => y <= x")?;
let model = ws1s.model(&psi, &Options::new())?.expect("satisfiable");
let Some(&Value::Position(x)) = model.get("x") else { panic!("x is a position") };
assert!(x > 3);

§Semantics

A first-order variable is a position, a natural number. A second-order variable is a finite set of positions. Quantifiers range over all of them, so all1 x: ex1 y: x < y is valid (there is no last position), and ex2 X: 0 in X & all1 x: x in X => x + 1 in X is not (no finite set is closed under successor). A formula with free variables is valid if every assignment satisfies it.

Names and digits are ASCII; a name continues with letters, digits and _. The keywords ex1, ex2, all1, all2, in, sub, true, false and empty are not names. The case of a name fixes its kind, so a quantifier binds names of its order only. => is right associative, <=> left associative. A quantifier reaches as far right as possible: a & ex1 x: b | c is a & (ex1 x: (b | c)). A bound name hides the free variable and the outer bindings of the same name. Every free name is one variable of the Ws1s: formulas parsed by the same Ws1s share their free variables. The connectives and quantifiers nest at most 1000 deep; a long chain of & or | counts as a balanced tree.

§Encoding

An assignment is a word with one tape per variable, the bit at step i telling whether position i is in the set; zero columns may follow. A position is a set with one element: each atom accepts only singletons on its first-order tapes, the first-order quantifiers conjoin this constraint to their body (ex1 x: φ is ∃x. sing(x) ∧ φ, all1 x: φ is ¬∃x. sing(x) ∧ ¬φ), and so do the queries for the free first-order variables. The negation of an atom thus holds words that are no assignment, but these never reach an answer.
