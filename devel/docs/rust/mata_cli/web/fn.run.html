pub fn run(
    script: &str,
    inputs: &str,
    parameters: &str,
    time_limit: Option<Duration>,
) -> Exit
Expand description

Runs script as mata script run --expression SCRIPT does, with the named inputs and parameters of --input and --param, one NAME=VALUE per line of inputs and parameters.

The values the script prints go to standard output and the errors to standard error, each as soon as it is written, so a run that is stopped from outside keeps what it printed. Paths, those of inputs included, are relative to the current directory.

After time_limit, the run stops with an error before its next top-level form, function call or loop round. A library operation that is running is not interrupted, so the caller still needs a limit of its own.
