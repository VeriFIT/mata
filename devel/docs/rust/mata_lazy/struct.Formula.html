Struct Formula

pub struct Formula { /* private fields */ }
Expand description

A DAG of Boolean and relational operations over automata, checked for emptiness lazily.

Building a formula does no automata work. leaf copies an automaton, and the other builders add a node. is_empty and check explore only the macrostates they need.

A term of arity n denotes a relation over n-tuples of words of equal length, read in lock step, where one step reads one symbol on every tape (EPSILON pads a shorter word). The steps are what count: a step that pads every tape still is one (only a leaf’s own moves that pad every tape are silent), and a term of arity 0 holds a number of steps. The complement is taken over the tuples of concrete symbols of each tape’s alphabet, which a query computes from the leaves that share the tape.

pub fn leaf_over<I>( &mut self, automaton: &impl Automaton, alphabets: impl IntoIterator<Item = I>, ) -> Result<Term, Error>
where I: IntoIterator<Item: Into<Symbol>>,

A leaf as leaf, whose tape i also has the symbols of alphabets[i], read or not, so that a complement over the leaf includes them. A single alphabet applies to every tape. The symbols of Automaton::alphabet join them, in leaf too.

use mata_lazy::{Automaton, Formula, Symbol};

/// The words a*.
struct OnlyA;

impl Automaton for OnlyA {
    type State = ();

    fn arity(&self) -> usize { 1 }
    fn initial_states(&self) -> impl IntoIterator<Item = ()> { [()] }
    fn is_final(&self, (): ()) -> bool { true }
    fn for_each_move(&self, (): (), mut visit: impl FnMut(&[Symbol], ())) {
        visit(&[Symbol::from(b'a')], ());
    }
}

let mut formula = Formula::new();
let leaf = formula.leaf(&OnlyA)?;
// Without b in the alphabet, the complement of a* is empty.
let not_a = formula.complement(leaf)?;
assert!(formula.is_empty(not_a)?);
let leaf = formula.leaf_over(&OnlyA, [*b"ab"])?;
let not_a = formula.complement(leaf)?;
assert!(!formula.is_empty(not_a)?);
§Errors

As leaf, AlphabetCount if alphabets has neither one alphabet nor one per tape, or ReservedSymbol.

pub fn sync_product( &mut self, lhs: Term, rhs: Term, synchronized: &[(usize, usize)], layout: &[Tape], ) -> Result<Term, Error>

The synchronized product, which holds the tuples of both operands whose synchronized tape pairs read the same words, arranged by layout. Tapes missing from layout are dropped.

use mata_lazy::{Automaton, Formula, Symbol, Tape};

/// The single pair (x, y).
struct Pair(u8, u8);

impl Automaton for Pair {
    type State = bool;

    fn arity(&self) -> usize { 2 }
    fn initial_states(&self) -> impl IntoIterator<Item = bool> { [false] }
    fn is_final(&self, read: bool) -> bool { read }
    fn for_each_move(&self, read: bool, mut visit: impl FnMut(&[Symbol], bool)) {
        if !read {
            visit(&[self.0.into(), self.1.into()], true);
        }
    }
}

let mut formula = Formula::new();
let ab = formula.leaf(&Pair(b'a', b'b'))?;
let bc = formula.leaf(&Pair(b'b', b'c'))?;
// {(a, b, c)}: tape 1 of `ab` meets tape 0 of `bc`.
let layout = [Tape::Lhs(0), Tape::Lhs(1), Tape::Rhs(1)];
let abc = formula.sync_product(ab, bc, &[(1, 0)], &layout)?;
assert_eq!(formula.arity(abc)?, 3);
assert!(!formula.is_empty(abc)?);
// Tape 0 of `ab` reads a, tape 0 of `bc` reads b.
let none = formula.sync_product(ab, bc, &[(0, 0)], &[])?;
assert!(formula.is_empty(none)?);
§Errors

SyncTapeOutOfRange, RepeatedSyncTape if a tape is synchronized twice or a result tape (or its synchronized peer) appears twice in layout, or ForeignTerm.

pub fn prefixes(&mut self, term: Term) -> Result<Term, Error>

The prefix closure {u | ∃v: u·v ∈ term}, taken over steps: a prefix keeps the first steps of all tapes together, padding included. It is empty when term is, and holds the empty word otherwise.

A query decides whether a macrostate of term reaches an accepting one with a search from it, whose answers it keeps; leaves and explicit nodes are trimmed, so for them it needs none. With this, term’s macrostates and their subsumption carry over unchanged.

use mata_lazy::Formula;
use mata_lazy::regex::Regex;

let mut formula = Formula::new();
let abc = formula.leaf(&Regex::new("abc")?)?;
let ab = formula.leaf(&Regex::new("ab")?)?;
let ac = formula.leaf(&Regex::new("ac")?)?;
let prefixes = formula.prefixes(abc)?;
let has_ab = formula.intersection(prefixes, ab)?;
let has_ac = formula.intersection(prefixes, ac)?;
assert!(!formula.is_empty(has_ab)? && formula.is_empty(has_ac)?);

pub fn explicit_with( &mut self, term: Term, options: ExplicitOptions, ) -> Result<Term, Error>

The same relation, built as an explicit automaton when a query starts.

The query explores term completely, numbers its macrostates densely, trims the result and takes its quotient by bisimulation. When the subset construction over tuples of the quotient stays within four times its states, sixteen times its states in members of all subsets and sixteen times its moves, the result is minimized; otherwise the quotient is kept. Then the query reads it like a leaf, with a simulation of its own. Explicit nodes stacked on each other therefore keep the size of their languages, not of their products. The query’s limits hold through this work, and an automaton built in full is kept even if the query then passes a limit. Rewrites stop at this node. Materialized automata are reused by later queries over the same alphabets (see clear_cache). When the exploration passes options.max_states, the node stays lazy.

pub fn check_portfolio( &self, term: Term, options: &Options, plans: &[Plan], ) -> Result<(usize, Outcome), Error>

Checks term under each of plans at once, one thread per plan, and returns the first answer with the index of its plan; the other queries stop. Every plan keeps the answer (see Plan), so only the time to it depends on the plans. options holds for every query, its own plan replaced.

A plan whose thread cannot be started (as on WebAssembly without threads) runs on the calling thread, before the plans after it are started.

§Errors

InvalidPlan for no plans, ForeignTerm for term, and when every query fails, the error of the first plan (as of check).
