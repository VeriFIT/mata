rustfst transducers as leaves.

A [VectorFst] or a [ConstFst] is a leaf of arity 2, where tape 0 reads the input labels and tape 1 the output labels. Label 0 ([EPS_LABEL]) is padding, and label n > 0 is the symbol n, so the largest label is EPSILON and the one below it ANY. An acceptor is the identity relation of its language; formula.project(leaf, &[0]) gives the language.

Weights only decide whether a transition or a final weight exists. Zero ones are dropped, so the leaf holds the paths whose weights are all nonzero. That is the support of the weighted relation when nonzero weights neither multiply nor add up to zero (no zero divisors, zero-sum-free addition). Like a Mata transducer, an FST is read in lock step, while rustfst aligns epsilon asynchronously.

use mata_lazy::Formula;
use rustfst::fst_impls::VectorFst;
use rustfst::fst_traits::MutableFst;
use rustfst::semirings::{Semiring, TropicalWeight};
use rustfst::Tr;

// a ↦ b, any number of times.
let mut fst = VectorFst::<TropicalWeight>::new();
let q = fst.add_state();
fst.set_start(q)?;
fst.set_final(q, TropicalWeight::one())?;
fst.add_tr(q, Tr::new(1, 2, TropicalWeight::new(0.5), q))?;

let mut formula = Formula::new();
let relation = formula.leaf(&fst)?;
let outputs = formula.project(relation, &[1])?;
assert!(!formula.is_empty(outputs)?);
