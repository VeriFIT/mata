Leaves from regex-automata DFAs.

A DFA reads bytes, and a byte is the symbol of the same number, as in Mata’s from_regex. So a regex-automata leaf and a Mata leaf of the same pattern read the same symbols.

use mata_lazy::Formula;
use mata_lazy::regex::Regex;

let mut formula = Formula::new();
let ab = formula.leaf(&Regex::new("(ab)*")?)?;
let a_or_b = formula.leaf(&Regex::new("[ab]*")?)?;
let not_a_or_b = formula.complement(a_or_b)?;
let difference = formula.intersection(ab, not_a_or_b)?;
assert!(formula.is_empty(difference)?);
