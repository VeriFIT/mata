The WebAssembly module of the website playground’s Script mode, built for wasm32-unknown-emscripten with the link options of build.rs. The page’s worker calls mata_script_run through Emscripten’s ccall; main is not run.

mata_script_run⚠
Runs a script with mata_cli::web::run and returns the exit status of mata script run. inputs and parameters hold one NAME=VALUE per line; a time_limit_ms of 0 sets no limit.
