Native build of Mata, the automata library of the VeriFIT group, and a cxx bridge to its NFA API (ffi) and its experimental transducer API (nft::ffi).

The mata crate is the safe API on top. The bridge is public so that other crates can add their own C++ code on the same libmata: build scripts get the headers as DEP_MATA_INCLUDE, and a bridge names the types as type Nfa = mata_sys::ffi::Nfa;.

§Conventions of the bridge

  • States and symbols are u32; counts and indices are usize.
  • Functions that can throw return Result<_, cxx::Exception>. The _within functions return null when a limit stopped them.
  • Every function is safe to call: the shim checks the preconditions that Mata checks only in debug builds.
  • Automata never carry an alphabet; alphabets are passed per call.
  • Language operations remove epsilon transitions first (on a copy), as Mata reads epsilon as a letter there.

§Build

The build script builds the Mata sources packaged with the crate (or, in the Mata repository, those of the repository), or uses an installed Mata. The crate README lists the requirements and options.

Modules§

ffi
The bridge: shared enums, the opaque C++ types and the shim functions (cxx/shim.hh).
nft
The bridge to Mata’s experimental transducers (mata::nft), over cxx/nft.hh. Every transducer it hands out is well formed: levels within range, initial and final states on level 0.
