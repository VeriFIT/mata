§mata

The crates.io and docs.rs links above are for the first published release, which is in preparation; until then, use this crate from the repository.

Safe Rust bindings to Mata, the finite automata library of the VeriFIT group at FIT BUT.

use mata::Nfa;

let a = Nfa::from_regex("(a|b)*abb")?;
let b = Nfa::from_regex("(a|b)*b")?;
assert!(a.is_included_in(&b));

// A word in L(b) but not in L(a).
let word = b.find_word_not_in(&a).expect("L(b) is larger");
assert!(b.accepts(&word) && !a.accepts(&word));

assert_eq!(a.minimize().num_states(), 4);

§Overview

  • Nfa is an automaton with states 0..num_states() (State) and transitions labelled with Symbols, which are plain numbers. Automata from Nfa::from_regex read bytes.
  • An Alphabet gives symbols names. Automata do not keep one; operations that need it borrow it.
  • Operations such as union, intersection, determinize and minimize return a new Nfa. &, | and - are intersection, union and difference.
  • Each check has a variant that returns a counterexample, such as is_included_in and find_word_not_in.
  • The _within methods stop at Limits, for the constructions that can blow up.
  • Nfa::parse_mata, Nfa::display_with and Nfa::dot read and write the .mata and DOT formats. Nfa::regex writes an RE2 regular expression. Symbols through 0xFF read back directly as one automaton through the Latin1 reader; larger values need a UTF-8 reader and decoding of the resulting automaton.
  • nft holds finite transducers. Mata’s transducers are experimental and moving fast, so expect breaking changes.
  • lazy checks Boolean and relational combinations of automata and transducers for emptiness lazily, building only what the answer needs (the mata-lazy crate, with Nfa and nft::Nft leaves).
  • logic decides formulas over variables encoded as words, such as Presburger arithmetic, on top of lazy (the mata-logic crate).

§Building

mata-sys builds Mata from source, which needs CMake 3.23 or newer and GCC 14 or newer or Clang 18 or newer (on macOS, Homebrew’s LLVM). The minimum supported Rust version is 1.95. See mata-sys for using an installed Mata or building to WebAssembly.

§Features

  • lazy (default): the lazy module.
  • logic (default): the logic module; enables lazy.
  • serde: Serialize and Deserialize for Nfa, Alphabet, State, Symbol and Transition.

strings
