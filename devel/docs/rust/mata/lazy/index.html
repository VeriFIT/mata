Lazy emptiness checking of Boolean and relational combinations of automata and transducers: the mata-lazy crate, with Mata’s Nfas and Nfts as leaves.

Everything of mata-lazy is here. This module adds the Automaton implementations of Nfa (arity 1) and Nft (one tape per level), the conversion of an ExplicitAutomaton into an Nft, and the conversions between Mata’s Symbol and this module’s Symbol, which keep the number. Mata’s EPSILON is EPSILON and its DONT_CARE is ANY, also in an Nfa.

use mata::Nfa;
use mata::lazy::Formula;

let mut formula = Formula::new();
let a = formula.leaf(&Nfa::from_regex("a(a|b)*")?)?;
let b = formula.leaf(&Nfa::from_regex("(a|b)*b")?)?;
// L(a) ⊆ L(b) iff L(a) ∩ ¬L(b) = ∅.
let not_b = formula.complement(b)?;
let difference = formula.intersection(a, not_b)?;
let witness = formula.find_word(difference)?.expect("`a` is not included");
assert_eq!(witness.tape(0), Some(vec![b'a'.into()]));
