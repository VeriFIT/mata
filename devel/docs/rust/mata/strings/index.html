String-solving operations: Mata’s mata::applications::strings, with its seg_nfa and replace namespaces.

The word queries work on the language: they remove epsilon transitions from a copy first, as the language checks of Nfa do, so epsilon never counts as a letter. The replace constructions build two-level transducers (input on level 0, output on level 1) over the symbols of an Alphabet.

use mata::strings::{self, ReplaceMode};
use mata::{Alphabet, Nfa, Symbol};

let (a, b) = (Symbol::from(b'a'), Symbol::from(b'b'));
let nfa = Nfa::from_regex("ab|ba|b")?;
assert_eq!(strings::shortest_words(&nfa), vec![vec![b]]);
assert_eq!(strings::longest_words(&nfa), Some(vec![vec![a, b], vec![b, a]]));

// Every a becomes b.
let alphabet = Alphabet::from_symbols([a, b])?;
let nft = strings::replace_reluctant_single_symbol(a, &[b], &alphabet, ReplaceMode::All)?;
assert!(nft.accepts(&[vec![a, b, a], vec![b, b, b]]));
