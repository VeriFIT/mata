The reluctant leftmost replace of the word literal by replacement over alphabet (Mata’s replace::replace_reluctant_literal). end_marker is a symbol the construction uses internally, END_MARKER by default.

§Errors

ReplaceError::ReservedMarker if end_marker is epsilon or DONT_CARE, and ReplaceError::ReservedSymbol if alphabet contains DONT_CARE or end_marker.
