pub struct Nft { /* private fields */ }
Expand description

A finite transducer: Mata’s mata::nft::Nft.

See the module documentation for how transitions are encoded. An Nft is always well formed: every state has a level below Nft::num_levels, initial and final states have level 0, and every edge leads to a later level or back to level 0.

§Thread safety

Nft is Send and Sync, as Nfa is.

Source

pub fn add_path<W: AsRef<[Symbol]>>( &mut self, source: State, words: &[W], target: State, ) -> Result<(), NftError>

Adds a path from source to target that reads words[i] on level i. Shorter words are padded with epsilon, so the path has as many transitions as the longest word. Symbol::EPSILON in a word reads nothing, so a word of epsilons only counts as empty.

use mata::nft::Nft;
use mata::Symbol;

let mut t = Nft::new(2)?;
let (p, q) = (t.add_state(), t.add_state());
t.add_initial(p)?;
t.add_final(q)?;
t.add_path(p, &[&b"abc".map(Symbol::from)[..], &b"x".map(Symbol::from)[..]], q)?;
assert!(t.accepts(&[&b"abc".map(Symbol::from)[..], &b"x".map(Symbol::from)[..]]));
§Errors

NftError::NoSuchState or NftError::NotLevelZero if source or target is not a state of level 0, NftError::LevelMismatch if words does not have one word per level, and NftError::EmptyPath if all words are empty (or epsilon only).

pub fn is_included_in(&self, other: &Nft) -> Result<bool, NftError>

Whether the relation of self is included in that of other, decided on the encodings.

true is always right; false only for transducers without epsilon. Mata compares the interleaved encodings, so reading (a, ε) and then (ε, b) differs from reading (a, b) at once, although both accept the pair (a, b). DONT_CARE counts as any symbol.

§Errors

pub fn compose_on( &self, other: &Nft, self_level: usize, other_level: usize, sync_level: SyncLevel, ) -> Result<Nft, NftError>

The composition synchronizing level self_level of self with level other_level of other, which sync_level keeps or projects out. The result has the levels of self before self_level, then those of other before other_level, then the synchronized level (if kept), then the remaining levels of self and of other.

Mata can also synchronize several levels at once; this binding does not offer that yet.

§Errors

NftError::NoSuchLevel if a level does not exist, NftError::NoLevelLeft if the result would have no level, and NftError::InvalidNumLevels if it would have more than MAX_LEVELS.

pub fn from_interleaved(nfa: &Nfa, num_levels: usize) -> Result<Nft, NftError>

The transducer whose interleaved encoding (see Nft::to_nfa) is nfa: Mata’s from_nfa_with_levels_advancing, which gives the initial states level 0 and every successor of a level-i state level i + 1 modulo num_levels. States unreachable from an initial state get level 0.

pub fn complement(&self, alphabet: &Alphabet) -> Result<Nft, NftError>

Mata’s complement (the classical algorithm) over the symbols of alphabet: determinizes, makes the transducer complete on every level and swaps the final and non-final states of level 0. A DONT_CARE edge is read as one edge per symbol of alphabet.

§Errors

NftError::EpsilonTransitions if the transducer has an epsilon edge, which Mata’s complement does not support.

§Panics

If alphabet contains DONT_CARE, which is not a letter.

§Complexity

Determinizes: exponential in the worst case.

Mata’s insert_levels: the result has a level per entry of mask, the existing levels in order at the false entries and a new level, as in Nft::insert_level, at every true entry.

pub fn revert(&self) -> Nft

Mata’s revert: every edge reversed, initial and final states swapped. A state of level i gets level n − i modulo n, so every word is reversed and the levels come in reverse order: level k of the result is level n − 1 − k of self. Nft::reverse keeps their order.

Source

pub fn is_universal(&self, alphabet: &Alphabet) -> bool

Mata’s Nft::is_universal (antichains): whether the interleaved encoding (see Nft::to_nfa) accepts every word over alphabet. Epsilon edges are removed first (Mata’s remove_epsilon), as Mata’s check takes no epsilon closure.

§Panics

If alphabet contains DONT_CARE, which is not a letter.

impl TryFrom<&ExplicitAutomaton> for Nft

One level per tape, trimmed as the automaton is. ANY stays as DONT_CARE, and to_nfa_over expands it for arity 1.

Mata reads padding asynchronously, so for a relation that is not length-preserving the Mata relation drops it: (a, ε) then (ε, b) is the pair (a, b) there. leaf_over reads the transducer back in lock step, given the alphabets.

§Errors

If Mata refuses the number of levels: 0 or more than MAX_LEVELS.
