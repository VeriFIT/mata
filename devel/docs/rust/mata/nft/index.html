Finite transducers: Mata’s experimental mata::nft::Nft.

A transducer with n levels (tapes) accepts a relation over n-tuples of words. Mata encodes one transducer transition as a chain of single-symbol edges through states of levels 0, 1, …, n − 1 and back to level 0: the edge leaving a level-i state reads the symbol of tape i. Symbol::EPSILON on a tape reads nothing there, and DONT_CARE reads any one symbol. Only the states of level 0 are the “real” states of the transducer; initial and final states always have level 0. Where an Nfa turns into a tape (Nft::identity, Nft::apply, Nft::restrict), a symbol of the automaton equal to DONT_CARE becomes the wildcard.

Mata’s transducer interface is experimental and moving fast, so expect breaking changes in this API.

use mata::nft::Nft;
use mata::{Nfa, Symbol};

let (a, b) = (Symbol::from(b'a'), Symbol::from(b'b'));
// Replace every `a` by `b`, keep every `b`.
let mut t = Nft::new(2)?;
let q = t.add_state();
t.add_initial(q)?;
t.add_final(q)?;
t.add_transition(q, &[a, b], q)?;
t.add_transition(q, &[b, b], q)?;

assert!(t.accepts(&[[a, b, a], [b, b, b]]));
assert!(!t.accepts(&[[a], [a]]));

// The image of a(a|b)* is b+.
let input = Nfa::from_regex("a(a|b)*")?;
let image = t.apply(&input, 0)?.to_nfa();
assert!(image.is_equivalent_to(&Nfa::from_regex("b+")?));
