Struct IntermediateAutomaton 

Source 
pub struct IntermediateAutomaton { /* private fields */ }
Expand description

One section of a .mata text as Mata’s parser reads it, before an automaton is constructed from it: Mata’s mata::IntermediateAut.

Nfa::parse_mata does the three steps of loading in one call; they are available separately as IntermediateAutomaton::parse_mata_all, IntermediateAutomaton::mintermize for sections with a bit-vector alphabet, and IntermediateAutomaton::construct_nfa or IntermediateAutomaton::construct_nft.

The Display form is Mata’s debugging dump of the section, not the .mata format.

§Examples

use mata::{Alphabet, IntermediateAutomaton};

let text = "@NFA-bits\n%Alphabet-auto\n%Initial q0\n%Final q1\nq0 (a0 & !a1) q1\n";
let parsed = IntermediateAutomaton::parse_mata_all(text)?;
let explicit = IntermediateAutomaton::mintermize(&[&parsed[0]])?;
let mut sigma = Alphabet::new();
let nfa = explicit[0].construct_nfa(&mut sigma)?;
assert_eq!(nfa.num_transitions(), 1);

pub fn parse_mata_all( text: &str, ) -> Result<Vec<IntermediateAutomaton>, ParseError>

Parses every section of a .mata text (Mata’s parser::parse_mf followed by IntermediateAut::parse_from_mf). Sections with a bit-vector alphabet keep their formulas.

§Errors

ParseError if the text is not valid.

Source

pub fn mintermize( automata: &[&IntermediateAutomaton], ) -> Result<Vec<IntermediateAutomaton>, IntermediateError>

Mintermizes automata together (Mata’s Mintermization::mintermize): the formulas over bit vectors become explicit symbols 0, 1, … that stand for the same minterms in every result, in the order of automata. Automata mintermized in separate calls do not share their minterms.

§Errors

IntermediateError::NotMintermizable unless every automaton is an NFA with a bit-vector alphabet.

Source

pub fn construct_nfa( &self, alphabet: &mut Alphabet, ) -> Result<Nfa, IntermediateError>

Constructs the NFA of an explicit NFA section (Mata’s nfa::builder::construct). Symbol names are read through alphabet as in Nfa::parse_mata, which adds the new ones; the numbers that mintermization gives the minterms of a section stay names of their symbols.

§Errors

IntermediateError::WrongKind if the section is not an NFA, IntermediateError::NeedsMintermization if it still has a bit-vector alphabet, and IntermediateError::Parse if it has a transition Mata cannot construct or alphabet has no symbol left for a new name.

Source

pub fn construct_nft( &self, alphabet: &mut Alphabet, ) -> Result<Nft, IntermediateError>

Constructs the transducer of an explicit NFT section (Mata’s nft::builder::construct), with symbol names as in IntermediateAutomaton::construct_nfa. Mata reads no %Levels or %LevelsNum on this path: every state is on level 0 of a two-level transducer, so each transition reads its symbol on both levels. Nft::parse_mata reads the levels.

§Errors

IntermediateError::WrongKind if the section is not an NFT, IntermediateError::NeedsMintermization if it has a bit-vector alphabet, and IntermediateError::Parse if it has a transition Mata cannot construct or alphabet has no symbol left for a new name.
