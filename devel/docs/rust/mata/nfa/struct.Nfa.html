Struct Nfa 

Source 
pub struct Nfa { /* private fields */ }
Expand description

A nondeterministic finite automaton with epsilon transitions: Mata’s mata::nfa::Nfa.

The states are 0..num_states(). Transitions are labelled with Symbols; Symbol::EPSILON labels epsilon transitions. An automaton holds no alphabet: operations that need one borrow an Alphabet.

Determinization, complementation, minimization, difference and the language checks remove epsilon transitions from a copy first, so they work on the language.

§Thread safety

Nfa is Send and Sync: distinct automata share no state, and &Nfa methods do not mutate.

§Examples

use mata::{Nfa, Symbol};

// (a|b)*b
let (a, b) = (Symbol::from(b'a'), Symbol::from(b'b'));
let mut nfa = Nfa::new();
let q0 = nfa.add_state();
let q1 = nfa.add_state();
nfa.add_initial(q0)?;
nfa.add_final(q1)?;
nfa.add_transition(q0, a, q0)?;
nfa.add_transition(q0, b, q0)?;
nfa.add_transition(q0, b, q1)?;

assert!(nfa.accepts(&[a, b]));
assert!(!nfa.accepts(&[b, a]));
assert!(nfa.is_equivalent_to(&Nfa::from_regex("(a|b)*b")?));

pub fn from_regex(pattern: &str) -> Result<Nfa, RegexError>

Builds an automaton from a regular expression in RE2 syntax, over bytes: symbol b is byte b. RE2 reads the pattern as Latin-1, so a non-ASCII literal is the sequence of its UTF-8 bytes, while a class or . matches single bytes ([é] is one of the two bytes of é, and . is any byte but \n). The result has no epsilon transitions and is trimmed and reduced by simulation. Anchors (^, $, \b) are ignored.

§Errors

RegexError if pattern is not valid RE2 syntax or is too large to compile.

§Complexity

The reduction by simulation takes time and memory quadratic in the size of the pattern. When memory runs out during it, Mata’s simulation code aborts the process.

use mata::{Nfa, Symbol};

let nfa = Nfa::from_regex("a(b|c)*")?;
assert!(nfa.accepts(&b"abcb".map(Symbol::from)));
assert!(Nfa::from_regex("a(").is_err());

pub fn parse_mata( text: &str, alphabet: &mut Alphabet, ) -> Result<Nfa, ParseError>

Parses an automaton in the .mata format. Symbol names are looked up in alphabet, and names not in it yet are added (see Alphabet::insert_name), so explicit automata parsed with the same alphabet agree on their symbols. An unnamed symbol of alphabet is read from its number, as Nfa::display_with prints it. <eps> is Symbol::EPSILON.

The text must hold exactly one automaton section: @NFA-explicit, or @NFA-bits, whose transition formulas are turned into one symbol per minterm. The minterms of one call are named 0, 1, … and mean nothing outside it, so parse bit-vector automata that are to be compared together, with Nfa::parse_mata_all. States are numbered in the order they first appear, and the largest state number sets the size of the automaton (bound it for untrusted input).

§Errors

ParseError if the text is not exactly one valid NFA section, or if alphabet has no symbol left below u32::MAX - 1 for a new name.

use mata::{Alphabet, Nfa};

let mut sigma = Alphabet::new();
let nfa = Nfa::parse_mata(
    "@NFA-explicit\n%Alphabet-auto\n%Initial q0\n%Final q1\nq0 a q1\nq1 b q1\n",
    &mut sigma,
)?;
let ab = sigma.encode(["a", "b"]).unwrap();
assert!(nfa.accepts(&ab));

pub fn words_up_to(&self, max_length: usize) -> Words<'_> ⓘ

The accepted words of length at most max_length, each once, in no particular order.

The words come from a search over sets of states, so a word with many runs costs no more than one. With GCC’s libstdc++, the search runs lazily as the iterator advances. LLVM’s libc++, the standard library on macOS, has no std::generator, so there this call runs the whole search first and stores every word: even words_up_to(30).take(1) can need memory for billions of words over two symbols.

use mata::{Nfa, Symbol};

let nfa = Nfa::from_regex("ab*")?;
let mut words: Vec<_> = nfa.words_up_to(3).collect();
words.sort();
assert_eq!(words, [&b"a"[..], b"ab", b"abb"].map(|w| w.iter().copied().map(Symbol::from).collect::<Vec<_>>()));

pub fn product( &self, other: &Nfa, condition: ProductFinalCondition, first_epsilon: Symbol, ) -> Nfa

The product of two automata, whose pairs of states are final according to condition (Mata’s product). Under ProductFinalCondition::And its language is the intersection. Under ProductFinalCondition::Or a pair is final when either state is. That is guaranteed to give the union when both automata have an initial state and are complete over the symbols either uses; otherwise a word that only one of them reads may be lost. Nfa::union is the union of any two automata, and Nfa::union_det_complete checks the requirements of the product union.
