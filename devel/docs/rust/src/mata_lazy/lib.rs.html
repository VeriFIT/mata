1//! Lazy emptiness checking of Boolean and relational combinations of automata and transducers.
2//!
3//! A [`Formula`] is a DAG of operations (union, intersection, complement, identity, projection,
4//! synchronized product, composition, images, prefix closure) over leaves. A leaf is any [`Automaton`], and the
5//! backends implement it for the automata of other crates. [`materialize`](Formula::materialize) builds the relation
6//! of a term as an [`ExplicitAutomaton`] that other crates can copy.
7//!
8//! | Backend | Leaves |
9//! |---|---|
10//! | `mata` crate, feature `lazy` (default) | Mata `Nfa` and `Nft`; this crate is re-exported as `mata::lazy`, which also turns an [`ExplicitAutomaton`] into an `Nft` |
11//! | feature `regex` | regex-automata DFAs (`Regex`), pure Rust |
12//! | feature `rustfst` | rustfst `VectorFst` and `ConstFst` transducers, pure Rust |
13//!
14//! This crate itself is pure Rust: it builds without a C++ toolchain, with the pure-Rust backends or with your own
15//! automata. Use it through `mata::lazy` for Mata leaves. Leaves of different backends mix in one formula, as they
16//! share [`Symbol`]s, numbered as in Mata.
17//!
18//! Building a formula does no automata work. A query ([`is_empty`](Formula::is_empty),
19//! [`check`](Formula::check)) explores only the macrostates it needs. Products pair states and complements
20//! build subsets on the fly, and simulation-based subsumption prunes macrostates that are below others. A term
21//! marked [`explicit`](Formula::explicit) is built as an automaton when a query starts and read like a leaf.
22//! A [`Plan`] chooses per query and term between lazy and explicit, and the operand order of products; an
23//! automatic intersection also reassociates to the cheapest pairwise shape. A
24//! [`Policy`] computes one from the [`view`](Formula::view) of a formula. A plan changes the cost of a query,
25//! never its answer. With the feature `serde`, plans, views and statistics are JSON.
26//!
27//! ```
28//! # #[cfg(feature = "regex")] {
29//! use mata_lazy::Formula;
30//! use mata_lazy::regex::Regex;
31//!
32//! let mut formula = Formula::new();
33//! let a = formula.leaf(&Regex::new("a(a|b)*")?)?;
34//! let b = formula.leaf(&Regex::new("(a|b)*b")?)?;
35//! // L(a) ⊆ L(b) iff L(a) ∩ ¬L(b) = ∅.
36//! let not_b = formula.complement(b)?;
37//! let difference = formula.intersection(a, not_b)?;
38//! let witness = formula.find_word(difference)?.expect("`a` is not included");
39//! assert_eq!(witness.tape(0), Some(vec![b'a'.into()]));
40//! # }
41//! # Ok::<(), Box<dyn std::error::Error>>(())
42//! ```
43//!
44//! # Semantics
45//!
46//! - **Lock step.** A relation of arity *n* is a language over *n*-tuples of symbols, and one step reads one
47//!   symbol on every tape. [`EPSILON`](Symbol::EPSILON) pads a tape and matches only padding.
48//!   [`ANY`](Symbol::ANY) reads any symbol of the tape's alphabet, the same one on both tapes of an identity.
49//!   This is exact for length-preserving relations and for relations whose padding lines up, as in regular
50//!   model checking. Mata and rustfst align padding asynchronously, so their own operations can give other
51//!   relations on transducers that pad.
52//! - **Symbols.** A byte is the symbol of the same number, so a regex and a Mata NFA of one pattern read the
53//!   same symbols. A rustfst label `n` is the symbol `n`, and label 0 is padding.
54//! - **Alphabets.** Tapes that must read the same symbols share an alphabet, such as both operands of an
55//!   intersection, the synchronized tapes of a product and both tapes of an identity. It holds every concrete
56//!   symbol that a leaf reads or declares ([`leaf_over`](Formula::leaf_over)) on these tapes, and for the
57//!   checked term also the symbols of the query ([`alphabet`](Options::alphabet)). The same complement can
58//!   therefore mean different things in different queries.
59//! - **Complement** is taken over the tuples of concrete symbols of the alphabets, so it holds no padding and
60//!   no wildcards. A double complement gives the term back only when the term has no padded words.
61//! - **Leaves.** [`leaf`](Formula::leaf) copies the part of the automaton reachable from its initial states,
62//!   without silent moves (moves that pad every tape, such as epsilon transitions) and without the states
63//!   that reach no final state. Only leaves drop such moves. A projection keeps a step whose kept tapes all
64//!   read padding, so the projection of {(ε, a)} on tape 0 is one step of padding, and its complement still
65//!   holds the empty word.
