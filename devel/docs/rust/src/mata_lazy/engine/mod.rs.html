1//! One query over a formula.
2//!
3//! # Steps
4//!
5//! 1. `exec` rewrites the formula into an execution DAG (its docs list the rewrites), builds equal nodes once
6//!    and puts the cheaper operand first. Rewrites do not look into explicit nodes.
7//! 2. `alphabet` groups the tapes into classes that read the same symbols and gives each class its alphabet.
8//! 3. Explicit nodes, children first, are explored completely, numbered densely, trimmed and replaced by the
9//!    leaf they give. The formula keeps that leaf for later queries, keyed by the node and the alphabets below
10//!    it. A node whose exploration passes its `max_states` stays lazy.
11//! 4. The search explores the root's macrostates depth first (breadth first for the fewest steps) until one
12//!    accepts, and returns the path to it. Under a length bound it expands no macrostate reached in that many
13//!    steps, and expands one again when it reaches it in fewer steps than before.
14//!
15//! | Node | Macrostate | Accepting | Successors |
16//! |---|---|---|---|
17//! | leaf, explicit | a state | final | its moves |
18//! | union (n-ary) | (branch, state) | that state | the branch's moves |
19//! | intersection, sync product, diagonal | (state, state) | both | pairs of moves whose tuples merge, once each when the product drops tapes |
20//! | complement | a minimized set of child states | no member | one move per tuple of the alphabets |
21//! | identity, projection | the child's | the child's | the child's moves, relabelled |
22//! | prefix closure | the child's | it reaches an accepting one (`prefixes`) | the child's moves |
23//!
24//! # Successors
25//!
26//! The successors of a macrostate (its post) are built from the children's posts when first needed (`post`)
27//! and cached per node, except for identities and along the root. A product joins each left move with the
28//! right moves that agree on the synchronized tapes. The post of a complement is a table of all tuples in a
29//! fixed order, so the matching moves follow from the letters. A sync product that drops its only synchronized
30//! pair, as in a composition or an image, joins groups of moves instead (`join`). A complement over at most 256
31//! child states builds its posts from bitset rows (`dense`). Every path gives the same posts and the same
32//! macrostate numbers.
33//!
34//! # Subsumption
35//!
36//! `s ⊑ t` implies that `s` accepts a subset of what `t` accepts (`subsumption`). Leaves use their maximal
37//! direct simulation (the `simulation` module), products compare componentwise, and complement sets
38//! `S ⊑ T` when every member of `T` is below a member of `S`. Complement sets drop the members below another
39//! member. Each node keeps the results it computed (`memo`), except a complement over a leaf, which compares
40//! sets through the closures of the transposed simulation (`closure`). The root keeps an antichain of the
41//! macrostates explored, grouped by the shape of the root so that a new macrostate is compared only with those
42//! it can be below.
43//!
44//! # Initial macrostates
45//!
46//! Intersected unions multiply their initial macrostates (`initial`). A node with at most 2¹⁶ lists them, and
47//! one with more numbers them on demand in the same order. The search then takes them one at a time, which can
48//! change the witness and the statistics but not the answer.
49//!
50//! # Memory and limits
51//!
52//! Most of the memory is cached posts. A post stores its tuples flat and each target as a `u32` with the
53//! accepting flag in the top bit, and the posts of one complement share their tuple table. Under a cache budget
54//! the query drops posts by GreedyDual-Size with frequency (`cache`) and computes them again when needed.
55//! `budget` counts macrostates and steps against the query's limits.
56//!
57//! Intersections stay binary, so `¬(A₁ ∪ … ∪ Aₙ)` builds quadratically many pair macrostates.

101/// Successors, initial macrostates and subsumption recurse once per level of the DAG; the stack grows by
102/// this much whenever less than [`RED_ZONE`] is left.
103const STACK_GROWTH: usize = 1 << 20;
104const RED_ZONE: usize = 64 << 10;
105
106fn deep<T>(work: impl FnOnce() -> T) -> T {
107	stacker::maybe_grow(RED_ZONE, STACK_GROWTH, work)
108}

116/// What the automaton of an explicit node depends on, which is the alphabet of every tape below it and the keys
117/// of the explicit nodes below it.
118#[derive(Debug, PartialEq, Eq, Hash)]
119struct Signature {
120	/// The distinct alphabets, in the order the tapes first reach them.
121	universes: Vec<Box<[Symbol]>>,
122	/// The tapes and the explicit nodes below, in an order that only the subterm decides.
123	items: Vec<Item>,
124}
125
126/// One entry of a [`Signature`].
127#[derive(Debug, PartialEq, Eq, Hash)]
128enum Item {
129	/// A tape, by the index of its alphabet.
130	Tape(u32),
131	/// An explicit node below, by the number of its key, so that its own tapes are not copied again.
132	Explicit(u64),
133}

135/// The automata of the explicit nodes of a formula, kept for later queries.
136#[derive(Debug, Default)]
137pub(crate) struct ExplicitCache {
138	/// The number of every key, by which the keys of the explicit nodes above refer to it.
139	numbers: FxHashMap<(NodeId, Signature), u64>,
140	/// The automata built, by key number.
141	leaves: FxHashMap<u64, Arc<Leaf>>,
142	/// The next number. Clearing the cache does not reuse numbers, so a query running meanwhile cannot mix keys.
143	next: u64,
144}
145
146impl ExplicitCache {
147	/// The number of `key`, given now if the key is new.
148	fn number(&mut self, key: (NodeId, Signature)) -> u64 {
149		match self.numbers.entry(key) {
150			Entry::Occupied(entry) => *entry.get(),
151			Entry::Vacant(entry) => {
152				self.next += 1;
153
154				*entry.insert(self.next - 1)
155			}
156		}
157	}
158
159	pub(crate) fn clear(&mut self) {
160		self.numbers.clear();
161		self.leaves.clear();
162	}
163}

240	/// Prepares the query of `root` and builds its explicit nodes; setting `cancel` stops it.
241	pub(crate) fn new(
242		formula: &'f Formula,
243		root: NodeId,
244		options: &Options,
245		cancel: Option<Arc<AtomicBool>>,
246	) -> Result<Engine<'f>, Error> {
247		let budget = Budget::new(options, cancel);
248		let annotations = Annotations::new(formula, options)?;
249		let exec = exec::build(formula, root, &annotations);
250		let alphabets = Alphabets::new(&exec, &root_symbols(options, exec.nodes[exec.root].arity)?);
251
252		for (id, node) in exec.nodes.iter_enumerated() {
253			if matches!(node.op, Op::Complement(_))
254				&& exec.reachable[id]
255				&& alphabets.tuple_count(id).is_none()
256			{
257				return Err(Error::ComplementTooLarge { arity: node.arity });
258			}
259		}
260
261		let num_nodes = exec.nodes.len();
262		let stores = exec
263			.nodes
264			.iter()
265			.map(|node| match node.op {
266				Op::Union(_) | Op::PadClosure(..) => Store::Tagged(IndexSet::default()),
267				Op::Intersection(..) | Op::Sync(..) | Op::Diagonal(..) => {
268					Store::Pair(IndexSet::default())
269				}
270				Op::Complement(_) => Store::Set(IndexSet::default()),
271				_ => Store::None,
272			})
273			.collect();
274		let mut cached: TiVec<ExecId, bool> = exec
275			.nodes
276			.iter()
277			.map(|node| !matches!(node.op, Op::Identity(_)))
278			.collect();
279		for node in exec.sharing(exec.root) {
280			cached[node] = false;
281			if matches!(exec.nodes[node].op, Op::Prefixes(_)) {
282				break;
283			}
284		}
285
286		let plans = join::plans(&exec);
287		let dense = exec
288			.nodes
289			.iter()
290			.map(|node| matches!(node.op, Op::Complement(_)).then(Box::default))
291			.collect();
292
293		let mut engine = Engine {
294			formula,
295			exec,
296			alphabets,
297			stores,
298			posts: vec![Vec::new(); num_nodes].into(),
299			cached,
300			tables: vec![None; num_nodes].into(),
301			// Rows of dense complements are keyed after the nodes.
302			cache_budget: options
303				.cache_budget
304				.map(|limit| CacheBudget::new(limit, 2 * num_nodes)),
305			nested_nanos: 0,
306			initial_counts: vec![None; num_nodes].into(),
307			initials: vec![None; num_nodes].into(),
308			union_starts: vec![None; num_nodes].into(),
309			accepting_initials: vec![None; num_nodes].into(),
310			live: vec![FxHashMap::default(); num_nodes].into(),
311			plans,
312			join_scratch: Scratch::default(),
313			join_buffers: JoinBuffers::default(),
314			subsumption: Subsumption::new(options.subsumption, num_nodes, budget.until()),
315			antichain: options.subsumption && options.antichain,
316			max_length: options.max_length,
317			shortest: options.shortest,
318			dense,
319			pad_steps: (0..num_nodes).map(|_| pad::PadSteps::default()).collect(),
320			budget,
321			stats: Stats::default(),
322			post_counts: vec![0; num_nodes].into(),
323		};
324
325		engine
326			.materialize_explicit()
327			.map_err(|limit| engine.limit_error(limit))?;
328
329		Ok(engine)
330	}

332	/// Builds every explicit node, children first.
333	fn materialize_explicit(&mut self) -> Result<(), Limit> {
334		let mut numbers: FxHashMap<ExecId, u64> = FxHashMap::default();
335		for node in self.exec.nodes.keys() {
336			if let Op::Explicit {
337				child,
338				options,
339				origin,
340			} = self.exec.nodes[node].op
341				&& self.exec.reachable[node]
342			{
343				let key = (origin, self.signature(node, &numbers));
344				let number = self.formula.explicit_cache.lock().number(key);
345				numbers.insert(node, number);
346				self.materialize_node(node, child, options, origin, number)?;
347			}
348		}
349
350		Ok(())
351	}

353	/// Replaces the explicit `node` by its automaton, or by its child once the exploration passes its budget.
354	fn materialize_node(
355		&mut self,
356		node: ExecId,
357		child: ExecId,
358		options: ExplicitOptions,
359		origin: NodeId,
360		number: u64,
361	) -> Result<(), Limit> {
362		let term = self.formula.term(origin);
363		// Looked up before the match, whose scrutinee would hold the lock through the insert.
364		let hit = self
365			.formula
366			.explicit_cache
367			.lock()
368			.leaves
369			.get(&number)
370			.cloned();
371
372		let (leaf, cached) = match hit {
373			Some(leaf) => (leaf, true),
374			None => match self.explore(child, options.max_states)? {
375				Explored::Done(raw) => {
376					// The reduction reads the clock as the exploration does, so a limit stops it too.
377					let budget = &mut self.budget;
378					let reduced = reduce(&raw, &mut || {
379						budget.step(0);
380						budget.passed()
381					});
382					let Ok(reduced) = reduced else {
383						return self.budget.check();
384					};
385					// A leaf built in full is kept even if the query then passes its limit, so a retry reuses it
386					// (only a reduction that a limit cut short is dropped).
387					let leaf = Arc::new(Leaf::build(&reduced, Vec::new()));
388					self.formula
389						.explicit_cache
390						.lock()
391						.leaves
392						.insert(number, Arc::clone(&leaf));
393
394					(leaf, false)
395				}
396				Explored::OverBudget(states) => {
397					self.stats.explicit.push(Materialized {
398						term,
399						states,
400						transitions: 0,
401						cached: false,
402						lazy: true,
403					});
404					self.exec.nodes[node].op = Op::Transparent(child);
405
406					return Ok(());
407				}
408			},
409		};
410
411		self.stats.explicit.push(Materialized {
412			term,
413			states: leaf.num_states(),
414			transitions: leaf.num_moves(),
415			cached,
416			lazy: false,
417		});
418		self.exec.nodes[node].op = Op::Leaf(LeafRef::Shared(leaf));
419
420		Ok(())
421	}

423	/// The alphabets that the language of the explicit `node` depends on, tape by tape.
424	fn signature(&self, node: ExecId, numbers: &FxHashMap<ExecId, u64>) -> Signature {
425		let mut signature = Signature {
426			universes: Vec::new(),
427			items: Vec::new(),
428		};
429		let mut positions: FxHashMap<usize, u32> = FxHashMap::default();
430		let mut seen: FxHashSet<ExecId> = FxHashSet::default();
431		let mut stack = vec![node];
432		while let Some(below) = stack.pop() {
433			if !seen.insert(below) {
434				continue;
435			}
436
437			// An explicit node below, keyed before, stands for its own subterm.
438			if let Some(&number) = numbers.get(&below) {
439				signature.items.push(Item::Explicit(number));
440
441				continue;
442			}
443
444			for tape in 0..self.exec.nodes[below].arity {
445				let class = self.alphabets.class(below, tape);
446				let position = match positions.entry(class) {
447					Entry::Occupied(entry) => *entry.get(),
448					Entry::Vacant(entry) => {
449						let position = u32::try_from(signature.universes.len())
450							.expect("fewer than 2^32 alphabets");
451						signature
452							.universes
453							.push(self.alphabets.class_universe(class).into());
454
455						*entry.insert(position)
456					}
457				};
458
459				signature.items.push(Item::Tape(position));
460			}
461
462			stack.extend(self.exec.nodes[below].op.children());
463		}
464
465		signature
466	}

468	/// Visits every macrostate of `node` reachable from its initial ones.
469	fn explore(&mut self, node: ExecId, max_states: Option<usize>) -> Result<Explored, Limit> {
470		fn intern(
471			ids: &mut IndexSet<StateId, FxBuildHasher>,
472			raw: &mut Raw,
473			target: Target,
474		) -> StateId {
475			let (index, new) = ids.insert_full(target.state);
476			if new {
477				raw.finals.push(target.accepting);
478			}
479
480			StateId::new(index)
481		}
482
483		let mut ids = IndexSet::default();
484		let mut raw = Raw::new(self.exec.nodes[node].arity);
485		// The initial macrostates in batches, so that the node's budget stops a node with very many.
486		for batch in batches(0..self.initial_count(node), INITIAL_BATCH) {
487			if max_states.is_some_and(|max| ids.len() > max) {
488				return Ok(Explored::OverBudget(ids.len()));
489			}
490
491			for index in batch {
492				let target = self.initial_at(node, index)?;
493				let state = intern(&mut ids, &mut raw, target);
494				raw.initial.push(state);
495			}
496		}
497
498		let mut next = 0;
499		while next < ids.len() {
500			if max_states.is_some_and(|max| ids.len() > max) {
501				return Ok(Explored::OverBudget(ids.len()));
502			}
503
504			self.budget.step(0);
505			self.stopped()?;
506
507			let source = StateId::new(next);
508			let post = self.post(node, ids[next])?;
509			for (tuple, target) in post.iter() {
510				let state = intern(&mut ids, &mut raw, target);
511				raw.push(source, tuple, state);
512			}
513
514			next += 1;
515		}
516
517		Ok(Explored::Done(raw))
518	}

520	/// Searches the root for an accepting macrostate, skipping subsumed macrostates; returns the witness, or `None`
521	/// and whether a macrostate was left unexpanded at the length bound.
522	pub(crate) fn search(&mut self) -> Result<(Option<Witness>, bool), Error> {
523		self.find_accepting()
524			.map_err(|limit| self.limit_error(limit))
525	}
526
527	fn find_accepting(&mut self) -> Result<(Option<Witness>, bool), Limit> {
528		let root = self.exec.root;
529		let arity = self.exec.nodes[root].arity;
530		// Under a bound or for the fewest steps, a macrostate is only below one reached in at most as many steps.
531		let by_depth = self.max_length.is_some() || self.shortest;
532		let mut search = Search {
533			antichain: self.antichain.then(|| Antichain::new(&self.exec, by_depth)),
534			reached: FxHashMap::default(),
535			tuples: Vec::new(),
536			work: VecDeque::new(),
537			bounded: false,
538		};
539
540		// An accepting initial macrostate gives the witness ε; with more than are listed, it is asked for first.
541		if !self.is_listed(root) && self.has_accepting_initial(root)? {
542			return Ok((Some(Witness::new(arity, Vec::new())), false));
543		}
544
545		// The initial macrostates in batches, each searched depth first before the next is numbered; breadth first,
546		// they all start the first level.
547		for batch in self.search_order(root) {
548			for index in batch {
549				let target = self.initial_at(root, index)?;
550				if target.accepting {
551					return Ok((Some(Witness::new(arity, Vec::new())), false));
552				}
553
554				let initial = Reached {
555					step: None,
556					depth: 0,
557				};
558				match search.reached.entry(target.state) {
559					Entry::Vacant(entry) => {
560						entry.insert(initial);
561					}
562					// Reached from an earlier batch, in more steps.
563					Entry::Occupied(mut entry)
564						if self.max_length.is_some() && entry.get().depth > 0 =>
565					{
566						entry.insert(initial);
567					}
568					Entry::Occupied(_) => continue,
569				}
570
571				self.enqueue(&mut search, target.state, 0);
572				self.stopped()?;
573			}
574
575			if !self.shortest
576				&& let Some(witness) = self.expand(&mut search)?
577			{
578				return Ok((Some(witness), false));
579			}
580		}
581
582		let witness = self.expand(&mut search)?;
583		let bounded = witness.is_none() && search.bounded;
584
585		Ok((witness, bounded))
586	}

588	/// Expands the macrostates of the search's work until one has an accepting successor, which gives the witness.
589	fn expand(&mut self, search: &mut Search<'f>) -> Result<Option<Witness>, Limit> {
590		let root = self.exec.root;
591		loop {
592			let next = if self.shortest {
593				search.work.pop_front()
594			} else {
595				search.work.pop_back()
596			};
597			let Some((state, depth)) = next else {
598				return Ok(None);
599			};
600
601			// Reached again in fewer steps since it was pushed, or dropped from the antichain.
602			if search.reached[&state].depth < depth
603				|| search
604					.antichain
605					.as_ref()
606					.is_some_and(|antichain| antichain.is_pruned(state))
607			{
608				continue;
609			}
610
611			if self
612				.max_length
613				.is_some_and(|max_length| depth >= max_length)
614			{
615				search.bounded = true;
616				continue;
617			}
618
619			self.budget.step(0);
620			self.stopped()?;
621
622			let post = self.post(root, state)?;
623			self.stats.explored += 1;
624			for (tuple, target) in post.iter() {
625				if target.accepting {
626					return Ok(Some(self.witness(
627						&search.reached,
628						&search.tuples,
629						state,
630						tuple,
631					)));
632				}
633
634				let reached = Reached {
635					step: Some(Step {
636						parent: state,
637						offset: search.tuples.len(),
638					}),
639					depth: depth + 1,
640				};
641				match search.reached.entry(target.state) {
642					Entry::Vacant(entry) => {
643						entry.insert(reached);
644					}
645					// Depth first under a bound, a macrostate reached in fewer steps is expanded again, as more of its
646					// successors are within the bound. Breadth first, the first steps are the fewest.
647					Entry::Occupied(mut entry)
648						if self.max_length.is_some() && entry.get().depth > depth + 1 =>
649					{
650						entry.insert(reached);
651					}
652					Entry::Occupied(_) => continue,
653				}
654
655				search.tuples.extend_from_slice(tuple);
656				self.enqueue(search, target.state, depth + 1);
657				self.stopped()?;
658			}
659		}
660	}
661
662	/// Adds `state`, reached in `depth` steps, to the search's work unless the antichain prunes it.
663	fn enqueue(&mut self, search: &mut Search<'f>, state: StateId, depth: usize) {
664		let added = match &mut search.antichain {
665			Some(antichain) => {
666				self.budget.step(0);
667
668				antichain.insert(
669					&self.exec,
670					&self.stores,
671					&mut self.subsumption,
672					state,
673					depth,
674				)
675			}
676			None => true,
677		};
678
679		if added {
680			search.work.push_back((state, depth));
681		} else {
682			self.stats.pruned += 1;
683		}
684	}

686	/// The word to `state` and then `last`, with each wildcard as the first symbol of its tape.
687	fn witness(
688		&self,
689		reached: &FxHashMap<StateId, Reached>,
690		tuples: &[Symbol],
691		mut state: StateId,
692		last: &[Symbol],
693	) -> Witness {
694		let root = self.exec.root;
695		let arity = self.exec.nodes[root].arity;
696		let mut steps = vec![last];
697		// Each step leads to a macrostate reached in more steps than its parent, so the walk ends.
698		while let Some(&Reached {
699			step: Some(Step { parent, offset }),
700			..
701		}) = reached.get(&state)
702		{
703			steps.push(&tuples[offset..offset + arity]);
704			state = parent;
705		}
706
707		let symbols = steps
708			.into_iter()
709			.rev()
710			.flat_map(|step| step.iter().enumerate())
711			.map(|(tape, &symbol)| {
712				if symbol == Symbol::ANY {
713					let universe = self.alphabets.universe(root, tape);
714
715					universe.first().copied().unwrap_or(Symbol::ANY)
716				} else {
717					symbol
718				}
719			})
720			.collect();
721
722		Witness::new(arity, symbols)
723	}

725	/// Builds the root as an explicit automaton, over the alphabets of its tapes.
726	pub(crate) fn materialize_root(&mut self) -> Result<Leaf, Error> {
727		let explored = self
728			.explore(self.exec.root, None)
729			.map_err(|limit| self.limit_error(limit))?;
730		let Explored::Done(raw) = explored else {
731			unreachable!("exploration without a state budget finishes")
732		};
733
734		let root = self.exec.root;
735		let alphabets = (0..self.exec.nodes[root].arity)
736			.map(|tape| self.alphabets.universe(root, tape).to_vec())
737			.collect();
738
739		Ok(Leaf::build(&raw, alphabets))
740	}

742	/// The limit that the query passed, if it did. The posts and initial macrostates computed since may then
743	/// be partial, and the query stops.
744	fn stopped(&self) -> Result<(), Limit> {
745		// Late once its `Until` passed: the deadline, or else the cancellation.
746		if self.subsumption.is_late() {
747			return Err(if self.budget.is_cancelled() {
748				Limit::Cancelled
749			} else {
750				Limit::Time
751			});
752		}
753
754		self.budget.check()
755	}

757	/// The error of passing `limit`, with the statistics so far.
758	fn limit_error(&self, limit: Limit) -> Error {
759		let stats = Box::new(self.stats());
760
761		match limit {
762			Limit::States => Error::StateLimit {
763				max_states: self.budget.max_states.expect("only a state limit passes"),
764				stats,
765			},
766			Limit::Time => Error::TimeLimit {
767				limit: self.budget.time_limit().expect("only a time limit passes"),
768				stats,
769			},
770			Limit::Cancelled => Error::Cancelled { stats },
771		}
772	}

774	pub(crate) fn stats(&self) -> Stats {
775		let nodes = self
776			.exec
777			.sources
778			.iter()
779			.map(|&(node, id)| {
780				let mut counted = id;
781				while let Op::Transparent(child) = self.exec.nodes[counted].op {
782					counted = child;
783				}
784
785				NodeStats {
786					term: self.formula.term(node),
787					macrostates: self.stores[self.exec.owner(id)].len(),
788					posts: self.post_counts[counted],
789				}
790			})
791			.collect();
792
793		Stats {
794			macrostates: self.stores.iter().map(Store::len).sum(),
795			dropped: self
796				.cache_budget
797				.as_ref()
798				.map_or(0, |budget| budget.dropped),
799			nodes,
800			..self.stats.clone()
801		}
802	}
803}

805/// The query's extra symbols of each tape of the root, whose arity is `arity`.
806fn root_symbols(options: &Options, arity: usize) -> Result<Vec<Vec<Symbol>>, Error> {
807	let mut root_symbols = vec![Vec::new(); arity];
808	for extra in &options.alphabets {
809		if let Some(&symbol) = extra.symbols.iter().find(|symbol| !symbol.is_concrete()) {
810			return Err(Error::ReservedSymbol { symbol });
811		}
812
813		let tapes = match extra.tapes {
814			Tapes::One(tape) if tape >= arity => return Err(Error::TapeOutOfRange { tape, arity }),
815			Tapes::One(tape) => tape..tape + 1,
816			Tapes::Every => 0..arity,
817		};
818
819		for tape in tapes {
820			root_symbols[tape].extend_from_slice(&extra.symbols);
821		}
822	}
823
824	Ok(root_symbols)
825}

827/// How many times the states of an explicit node's bisimulation quotient its subset construction may have.
828const DETERMINIZE_FACTOR: usize = 4;
829
830/// How many times the states of the quotient the members of all subsets of its subset construction may be. Few
831/// subsets can still hold most states each, as the suffixes of a chain whose states are all initial.
832const MEMBERS_FACTOR: usize = 16;
833
834/// How many times the moves of the quotient the moves of its subset construction may be. Few subsets can still
835/// have many moves each, the union of the distinct letters of their members.
836const MOVES_FACTOR: usize = 16;
837
838/// An explicit node's automaton made small: minimal when its subset construction stays within
839/// [`DETERMINIZE_FACTOR`] times the states of its bisimulation quotient, [`MEMBERS_FACTOR`] times them in members of
840/// all subsets and [`MOVES_FACTOR`] times its moves, that quotient otherwise. An explicit node above another reads
841/// the smaller one, so a chain of them (pre-images in regular model checking) does not grow level by level.
842fn reduce(raw: &Raw, stop: &mut dyn FnMut() -> bool) -> Result<Raw, Stopped> {
843	// Trimmed first: a dead successor would tell two states with the same language apart.
844	let quotient = raw.trimmed(stop)?.quotient(stop)?;
845	let states = quotient.finals.len();
846	match quotient.determinize(
847		states.saturating_mul(DETERMINIZE_FACTOR),
848		states.saturating_mul(MEMBERS_FACTOR),
849		quotient.num_moves().saturating_mul(MOVES_FACTOR),
850		stop,
851	)? {
852		Some(dfa) => dfa.trimmed(stop)?.minimize(stop),
853		None => Ok(quotient),
854	}
855}
