class NameStore
#include <parser.hh>

An append-only storage of names: the tokens of a parsed section and the formula nodes of an intermediate automaton keep views into it instead of strings of their own.

The bytes handed out are never moved, so a view stays valid for as long as the storage lives. Copies of parser::ParsedSection and of IntermediateAut share the storage, which keeps the views of the copies valid.

struct BodyToken¶
#include <parser.hh>

One token of a body line, with the flag telling whether the reader read it in quotes.

create_node() lets a quoted token be an operand even when it starts with & | or !, which the unquoted reader would take for an operator of the transition formula. The token is a view: parse_mf() points it into the name storage of its section, other code has to keep the bytes alive for as long as the token is used.
