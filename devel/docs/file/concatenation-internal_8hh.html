inline utils::SparseSet<State> connect_concatenation(Delta &delta, const utils::SparseSet<State> &lhs_final, const utils::SparseSet<State> &rhs_initial, const utils::SparseSet<State> &rhs_final, const State offset, const size_t num_of_states)¶

Connect the operands of an in-place concatenation whose rhs delta is already appended at offset.

Every lhs final state takes over the transitions of every shifted rhs initial state. The posts of the rhs initial states are first united into one connector post, which each lhs final state then merges in with one sorted union per symbol, instead of one Delta::add() per target.

Parameters:

  • lhs_final – [in] The lhs final states; may be the final states of the automaton owning delta.

  • num_of_states – [in] The number of states of the concatenation, which the returned set covers.

Returns:

The final states of the concatenation: the shifted rhs final states, and the lhs final states when an rhs initial state is final.
