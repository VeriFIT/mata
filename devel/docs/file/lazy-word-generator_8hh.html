class LazyWordGenerator
#include <lazy-word-generator.hh>

Fallback declaration used when the standard library does not implement std::generator (notably Apple’s system libc++, even under -std=c++23). The type stays declared so that the bindings-facing API (nfa::plumbing/nft::plumbing get_words_lazy_ptr()) has the same signature on every platform; it is never instantiated, because those functions throw instead of constructing one.
