File nfa.hh¶

Nondeterministic Finite Automata including structures, transitions and algorithms.

In particular, this includes:

  1. Structures (Automaton, Transitions, Results, Delta),

  2. Algorithms (operations, checks, tests),

  3. Constructions.

Other algorithms are included in mata::nfa::plumbing (simplified API for, e.g., bindings) and mata::nfa::algorithms (concrete implementations of algorithms, such as for complement).

namespace mata

Main namespace including structs and algorithms for all automata.

In particular, this includes:

  1. Alphabets,

  2. Formula graphs and nodes,

  3. Mintermization,

  4. Closed sets.

bool is_intersection_empty(const Nfa &lhs, const Nfa &rhs, Run *witness = nullptr, Symbol first_epsilon = EPSILON)¶

Check whether the language intersection of two NFAs is empty, without materializing the product.

Explores reachable pairs (state_of_lhs, state_of_rhs) directly and stops at the first pair that is final in both automata. The traversal moves on shared symbols in both automata at once and lets a symbol at or above first_epsilon move one side only – the same semantics that intersection(lhs, rhs, first_epsilon) materializes, but only up to the first witness.

Parameters:

  • lhs – [in] First NFA.

  • rhs – [in] Second NFA.

  • witness – [out] When not null and the intersection is nonempty, receives a word accepted by both automata (some valid word, not necessarily the shortest). One-sided epsilon moves (symbols at or above first_epsilon) are stripped. With the default first_epsilon, the word replays in both automata with Nfa::is_in_lang(witness, use_epsilon = true); that replay follows only EPSILON transitions, so with a custom first_epsilon, relabel the symbols at or above it to EPSILON before replaying.

  • first_epsilon – [in] Smallest symbol treated as a one-sided (epsilon) move.

Returns:

True iff there is no word accepted by both lhs and rhs.

Nfa left_quotient(const Nfa &nfa, const Nfa &prefixes, Symbol first_epsilon = EPSILON)¶

Compute the left quotient of the language of nfa by the language of prefixes.

The left quotient (derivative by a language) is { w | there is u in L(prefixes) with u.w in L(nfa) }: the words of nfa with a prefix from prefixes removed. With prefixes accepting a single word u, this is the Brzozowski derivative of nfa by u.

The result is nfa with its initial states replaced by the states of nfa reachable by reading a word of prefixes. These are found by exploring the reachable pairs (state_of_prefixes, state_of_nfa) directly, without materializing the product, and pairs with a useless state of prefixes are never explored. The result is not trimmed: call Nfa::trim() to remove the states no longer reachable.

Symbols at or above first_epsilon move one side only, as in intersection(lhs, rhs, first_epsilon), so epsilon transitions of both automata are supported. The epsilon transitions of nfa are kept in the result.

Parameters:

  • nfa – [in] NFA whose language is quotiented.

  • prefixes – [in] NFA accepting the prefixes to remove.

  • first_epsilon – [in] Smallest symbol treated as a one-sided (epsilon) move.

Returns:

NFA for the left quotient of nfa by prefixes.

Nfa right_quotient(const Nfa &nfa, const Nfa &suffixes, Symbol first_epsilon = EPSILON)¶

Compute the right quotient of the language of nfa by the language of suffixes.

The right quotient is { u | there is w in L(suffixes) with u.w in L(nfa) }: the words of nfa with a suffix from suffixes removed.

The result is nfa with its final states replaced by the states of nfa from which nfa accepts a word of suffixes. These are found as in left_quotient(), but backward: pairs of a state of the reverted suffixes and a state of nfa are explored from the final states of both, moving nfa against its transitions over an index of predecessors, without reverting nfa or materializing the product. The result is not trimmed: call Nfa::trim() to remove the states that no longer reach a final state.

Symbols at or above first_epsilon move one side only, as in intersection(lhs, rhs, first_epsilon), so epsilon transitions of both automata are supported. The epsilon transitions of nfa are kept in the result.

Parameters:

  • nfa – [in] NFA whose language is quotiented.

  • suffixes – [in] NFA accepting the suffixes to remove.

  • first_epsilon – [in] Smallest symbol treated as a one-sided (epsilon) move.

Returns:

NFA for the right quotient of nfa by suffixes.

bool are_equivalent(const Nfa &lhs, const Nfa &rhs, const ParameterMap &params = {{"algorithm", "antichains"}}, Run *cex = nullptr)¶

Perform equivalence check of two NFAs: lhs and rhs.

The current implementation of Nfa does not accept input alphabet. For this reason, an alphabet has to be created from all transitions each time an operation on alphabet is called. When calling this function, the alphabet has to be computed first.

Hence, this function is less efficient than its alternative taking already defined alphabet as its parameter. That way, alphabet has to be computed only once, as opposed to the current ad-hoc construction of the alphabet. The use of the alternative with defined alphabet should be preferred.

Epsilon transitions are removed from copies of the operands that have them.

  • rhs – [in] Second automaton to concatenate.

  • params – [in] Optional parameters to control the equivalence check algorithm:

    • ”algorithm”: “naive”, “antichains” (Default: “antichains”)

Nfa revert(const Nfa &aut)¶

Reverting the automaton by a counting sort (see Delta::reverted()): much faster than the three insertion-based variants below, which are kept for benchmarking.

Nfa fragile_revert(const Nfa &aut)¶

This revert algorithm is fragile, uses low level accesses to Nfa and static data structures, and is potentially dangerous when there are used symbols with large numbers (allocates an array indexed by symbols). It is asymptotically faster, however. For somewhat dense automata, the performance is the same or a little bit slower than simple_revert otherwise. Not affected by pre-reserving vectors.

Nfa simple_revert(const Nfa &aut)¶

Reverting the automaton by a simple algorithm, which does a lot of random access addition to Post and Move. Much affected by pre-reserving vectors.

Nfa somewhat_simple_revert(const Nfa &aut)¶

Reverting the automaton by a modification of the simple algorithm. It replaces random access addition to SymbolPost by push_back and sorting later, so far seems the slowest of all, except on dense automata, where it is almost as slow as simple_revert. Candidate for removal.

Remove states which are not accessible (unreachable; state is accessible when the state is the endpoint of a path starting from an initial state) or not co-accessible (non-terminating; state is co-accessible when the state is the starting point of a path ending in a final state).

The out-of-place trimming constructs the trimmed NFA directly from the useful states, so it does not copy the transitions of the useless states only to discard them. When many states are useless, this is faster than copying the NFA and trimming the copy in place. The alphabet and the attributes of nfa are carried over to the result.

Note

The states in the returned NFA are renumbered.

Parameters:

  • nfa – NFA to trim.

  • state_renaming – [out] Mapping of trimmed states to new states.

  • initial_states – Optional set of initial states to consider instead of nfa.initial_states. If std::nullopt, uses initial states of nfa.

  • final_states – Optional set of final states to consider instead of nfa.final_states. If std::nullopt, uses final states of nfa.

Returns:

A new NFA from nfa after trimming.

bool is_minimal() const

Test whether the automaton is a minimal deterministic automaton of its language.

Minimal in the sense of the result of ‘minimize()’: deterministic, trimmed (every state reachable and co-reachable, so the transition function may be partial and a sink state counts as redundant), and with no two equivalent states. The empty language is minimal only as a single non-final initial state without transitions. Runs in O(a*n*log(n)) by Hopcroft partition refinement.

Get the set of all words in the language of the automaton whose length is <= max_length.

If you have an automaton with finite language (can be checked using is_acyclic), you can get all words by calling get_words(aut.num_of_states())

The search goes over words, not over paths: the states reachable by a word are kept together as one macrostate, so the work is bounded by the number of distinct words of length <= max_length that have a run in the automaton, no matter how many accepting paths each of them has.
