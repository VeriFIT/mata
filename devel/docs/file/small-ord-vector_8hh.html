template<class Key, std::size_t InlineCapacity = std::max<std::size_t>(1, sizeof(std::uintptr_t) / sizeof(Key))>
class SmallOrdVector
#include <small-ord-vector.hh>

A set of keys kept as a sorted, duplicate-free contiguous array, like OrdVector, that stores up to InlineCapacity keys inside the object and allocates only for larger sets.

The object is a pointer-sized buffer plus a 32-bit size word: the buffer holds either the inline keys or a pointer to a heap block, which keeps its capacity in a header in front of the keys. A set lives inline until it outgrows InlineCapacity or a larger capacity is reserved. Like std::vector, it then keeps its heap block when it shrinks, while copies are made in their final form: inline when they fit, otherwise with exact capacity. On 64-bit targets the object ends with four bytes of tail padding, so a [[no_unique_address]] member followed by a 32-bit field packs both into 16 bytes.

Iterators are plain pointers; any operation that grows the set may invalidate them.
