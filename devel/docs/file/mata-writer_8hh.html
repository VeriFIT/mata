File mata-writer.hh¶

Writer of the .mata text of printed automata.

namespace mata

Main namespace including structs and algorithms for all automata.

In particular, this includes:

  1. Alphabets,

  2. Formula graphs and nodes,

  3. Mintermization,

  4. Closed sets.

namespace parser

Parser from .mata format to automata (currently Nfa and Nft are supported).

This includes parsing either from files or from other streams (strings, etc.).

class MataWriter
#include <mata-writer.hh>

Collects the text of a printed automaton in a string, formatting the numbers with std::to_chars() instead of the locale machinery of a stream, which took most of the time of printing.

The numbers are plain decimals whatever the format flags of the stream, as the parser reads them.
