MintermPartition compute_minterms_with_incidence(const std::vector<BDD> &source_bdds) const

Computes the same partition as compute_minterms() and additionally records, for each source BDD, which minterms lie below it.

The incidence is carried along the refinement: when a region is split by a source BDD, the part inside the BDD inherits the incidence of the region plus that BDD, and the part outside inherits it unchanged. No BDD operation is therefore needed afterwards to relate a source BDD to the minterms below it.

Parameters:

source_bdds – BDDs for which minterms are computed

struct MintermPartition
#include <mintermization.hh>

The minterm partition of a sequence of source BDDs together with the incidence between the two.

The minterms are numbered by their position in minterms, which is the order in which the refinement created them and therefore depends only on the input, not on the addresses CUDD assigned to the nodes.
