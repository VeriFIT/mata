Detailed Description

template<typename St, typename K, typename T>
struct mata::posts::Transition< St, K, T >

Transition with a source state, a key, and a target.

The key field is spelled symbol. A relation that wants other names, or more than one key, passes its own traits to DeltaBase instead.

See also
DefaultTransitionTraits.
Note
Transition{source, symbol, target} builds one, and parts() takes it apart again in the same order.
