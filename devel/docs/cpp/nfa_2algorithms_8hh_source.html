29/// @brief Reduction of the DFA of @c determinize_four_russians() and @c determinize_classical() to a smaller DFA for
30/// the same language, not always minimal.
31/// There is no real winner, but based on benchmarks, @c Adaptive is the best choice for general use.
32enum class DeterminizationReduction : std::uint8_t {
33 None, ///< No reduction.
34 Bisimulation, ///< Merge bisimilar states. Fast.
35 Simulation, ///< Also use the simulation. Smaller DFAs, but memory quadratic in the number of states.
36 Adaptive, ///< Start with @c Bisimulation, and switch to @c Simulation if the DFA turns out large.
37};

46/**
47 * @brief Determinize automaton by the "Four Russians" subset construction.
48 *
49 * This is the "Four Russians" technique of Arlazarov, Dinic, Kronrod and Faradzev (1970), applied lazily.
50 *
51 * Gives the DFA of @c determinize_classical() up to the numbering of the states, usually much faster on large
52 * automata. The default algorithm of @c determinize().
53 * The NFA states are cut into blocks, and the post of each combination of states of a block is computed once, when it
54 * first occurs, and kept in a table. The post of a macrostate is then a union over its blocks instead of its states.
55 *
56 * With a reduction, it gives a smaller DFA for the same language, not always minimal. A reduction usually lowers the
57 * memory usage. Its effect on the time varies: inputs whose DFA shrinks a lot are much faster, others may be slower.
58 *
59 * @code
60 * const Nfa dfa = algorithms::determinize_four_russians(aut);
61 * const Nfa smaller = algorithms::determinize_four_russians(aut, {.reduction = DeterminizationReduction::Adaptive});
62 * @endcode
63 *
64 * @param[in] aut Automaton to determinize.
65 * @param[in] options Block size and reduction.
66 * @param[out] subset_map Map that maps sets of states of input automaton to states of determinized automaton (with a
67 * reduction, merged states appear as one of them).
68 * @param[in] macrostate_discover Callback event handler for discovering a new macrostate for the first time, as in
69 * @c determinize(). Not allowed with a reduction.
70 * @param[in] restrict_to_symbols When not @c nullptr, determinize over these symbols only, as in @c determinize().
71 * @return Determinized automaton.
72 * @throws std::invalid_argument for an invalid block size, or for a reduction with @p macrostate_discover.
73 */
74Nfa determinize_four_russians(
75 const Nfa& aut,
76 const FourRussiansOptions& options = {},
77 std::unordered_map<StateSet, State>* subset_map = nullptr,
78 std::optional<std::function<bool(const Nfa&, State, const StateSet&)>> macrostate_discover = std::nullopt,
79 const utils::OrdVector<Symbol>* restrict_to_symbols = nullptr
80);

106/**
107 * Hopcroft minimization of automata. Based on the algorithm from the paper:
108 * "Efficient Minimization of DFAs With Partial Transition Functions" by Antti Valmari and Petri Lehtinen.
109 * The algorithm works in O(a*n*log(n)) time and O(m+n+a) space, where: n is the number of states, a is the size
110 * of the alphabet, and m is the number of transitions. [https://dl.acm.org/doi/10.1016/j.ipl.2011.12.004]
111 * @param[in] dfa_trimmed Deterministic automaton without useless states, with no empty symbol posts. Trim it before
112 * calling this function and drop empty posts from the delta first: an empty post is not a transition, but the core
113 * validates and refines posts as stored, so it cannot be accepted. Skipping the trimming is not an error, it only
114 * costs minimality.
115 * @throws std::invalid_argument If @p dfa_trimmed has a transition and is not deterministic, or has several
116 * initial states. A transition-free automaton with at most one initial state is returned without refinement.
117 * @return Minimized deterministic automaton, refined from @p dfa_trimmed. A transition-free
118 * automaton without an initial state is returned as it is, with no initial state: such a result is neither
119 * deterministic nor minimal by @c Nfa::is_deterministic() / @c Nfa::is_minimal(). Callers that need the canonical
120 * one-state empty-language DFA should use the public @c mata::nfa::minimize() dispatcher instead.
121 */
122Nfa minimize_hopcroft(const Nfa& dfa_trimmed);

129 * @param[in] aut Automaton to be minimized.
130 * @return Minimal deterministic automaton.

132Nfa minimize_hopcroft_nondet(const Nfa& aut);

146/**
147 * @brief Classes of states that have the same finality, the same level, and, over every symbol, successors in the
148 * same classes.
149 *
150 * Starts from the identity and merges states with identical successors, then states whose successors became
151 * identical by the merge, until nothing merges. Every merge joins classes with the same successors, so the
152 * partition stays a bisimulation and the quotient keeps the forward simulation of every state. It is far cheaper
153 * than the simulation itself: the first pass hashes each state post once, and after it only the classes of the
154 * predecessors of the states of an absorbed class are hashed again. The classes are numbered in the order of
155 * their smallest states.
156 *
157 * @param[in] aut Automaton whose states to classify.
158 * @param[in] num_of_states Number of states of @p aut.
159 * @param[in] levels Level of each state of a transducer. States past its end, and all states of an NFA, for which it
160 * is empty, are on level 0.
161 * @return The class of each state; the number of classes is one past the largest class.
162 */
163std::vector<State>
164 identical_successor_classes(const Automaton& aut, size_t num_of_states, std::span<const Level> levels = {});

201/**
202 * @brief Signature of a macrostate: the OR of @c 1 << (q % 64) over its states @c q.
203 *
204 * A superset can only have more bits set, so a bit present in @c macrostate_signature(a) and absent from
205 * @c macrostate_signature(b) exhibits a state of @c a that is missing from @c b and proves @c a ⊄ b. The converse
206 * does not hold: states that are congruent modulo 64 share a bit, so equal signatures prove nothing. The filter
207 * therefore only ever rejects, which is what the antichain subsumption tests need to stay sound.
208 */
209inline uint64_t macrostate_signature(const StateSet& macrostate) {
210 uint64_t signature{0};
211 for (const State state : macrostate) { signature |= UINT64_C(1) << (state & 63); }
212 return signature;
213}

229/**
230 * @brief Inclusion by bisimulation up to congruence (HKC), after F. Bonchi and D. Pous, "Checking NFA equivalence
231 * with bisimulations up to congruence", POPL 2013.
232 *
233 * Checks that the macrostates X ∪ Y and Y are equivalent for every pair of a macrostate X of @p smaller and Y of
234 * @p bigger reached over the same word, starting from the initial states. Unlike @c is_included_antichains(), which
235 * pairs single states of @p smaller with macrostates of @p bigger, it determinizes both automata on the fly. A pair
236 * is skipped when it lies in the congruence closure of the pairs stored before, which for this shape of pairs means
237 * that every state x of X lies in a stored pair whose macrostate of @p bigger is a subset of Y; a stored pair all of
238 * whose states of @p smaller are covered this way by pairs with smaller macrostates is not expanded either.
239 * @c EPSILON is an ordinary symbol here.
240 *
241 * @param[in] smaller Automaton which language should be included in the bigger one
242 * @param[in] bigger Automaton which language should include the smaller one
243 * @param[in] alphabet Alphabet of both automata (not needed by the algorithm)
244 * @param[out] cex A word of @p smaller rejected by @p bigger, with an accepting run of @p smaller over it, when the
245 * inclusion does not hold; cleared otherwise.
246 * @return True if the language of @p smaller is included in the language of @p bigger.
247 */
248bool is_included_hkc(const Nfa& smaller, const Nfa& bigger, const Alphabet* alphabet = nullptr, Run* cex = nullptr);

480/**
481 * @brief Reduce NFA to an automaton with the minimum number of states using an external SAT solver.
482 *
483 * Experimental. A counterexample-guided search: for k = 1, 2, ..., a SAT solver looks for an automaton with k states
484 * consistent with a set of sample words, the candidate is checked for equivalence with @p nfa, and a distinguishing
485 * word is added to the samples until the candidate is equivalent or no k-state automaton exists. The search is
486 * exponential in the worst case and is practical only for languages whose minimal automata have about ten states.
487 *
488 * By default, an @c EPSILON transition is treated as a transition over an ordinary letter, as in the other reduction
489 * algorithms. Set @p epsilon to "empty" to run @c remove_epsilon() on the input first instead.
490 * The result uses the symbols and the alphabet of @p nfa.
491 *
492 * @param[in] nfa NFA to reduce.
493 * @param[in] type Kind of the resulting automaton (values: "nfa", "dfa"):
494 * - "nfa": an NFA with the minimum number of states. It never has more states than @p nfa reduced by simulation.
495 * - "dfa": a deterministic (not necessarily complete) automaton with the minimum number of states.
496 * @param[in] solver Command running a SAT solver, as the solver's executable followed by its arguments separated by
497 * spaces. Parts containing spaces can be enclosed in single or double quotes; the command is not interpreted by a
498 * shell otherwise. The solver is given a DIMACS CNF file as its last argument and has to print the result in the
499 * format of the SAT competitions, that is, an "s SATISFIABLE" or "s UNSATISFIABLE" line and the model on "v" lines.
500 * If empty, the value of the environment variable @c MATA_SAT_SOLVER is used and, if that is not set, the first of
501 * @c cadical, @c kissat, @c cryptominisat5 and @c picosat found in @c PATH.
502 * @param[in] epsilon Whether to treat @c EPSILON as an ordinary letter ("letter", default) or remove it first as
503 * the empty word ("empty").
504 * @return An automaton equivalent to @p nfa with the minimum number of states of the given @p type.
505 * @throws ExternalSolverNotFound If no SAT solver can be found or run.
506 * @throws std::runtime_error If @p epsilon has an invalid value, the solver fails, or its output cannot be understood.
507 */
508Nfa reduce_sat(
509 const Nfa& nfa,
