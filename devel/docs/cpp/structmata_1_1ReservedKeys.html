Detailed Description

template<typename K, K MinEpsilon = std::numeric_limits<K>::max(), K MaxOrdinary = internal::default_max_ordinary<K>(MinEpsilon), bool EpsilonIsGreatest = internal::default_epsilon_is_greatest<K>(MinEpsilon)>
struct mata::ReservedKeys< K, MinEpsilon, MaxOrdinary, EpsilonIsGreatest >

The structure defines where the ordinary keys stop and the reserved tail begins.

The key order splits into three regions:

  • ordinary, up to and including max_ordinary
  • reserved but not epsilon, above max_ordinary and below min_epsilon
  • epsilon, from min_epsilon upwards

The middle region is empty by default, since MaxOrdinary defaults to one below MinEpsilon. Widening the reserved tail opens it, which is how a key can be reserved.

Template Parameters
KThe key type.
MinEpsilonThe smallest epsilon key: every key at or above it is an epsilon. Defaults to the largest value. A non-integral key has no default and must be spelled explicitly.
MaxOrdinaryThe largest key that is not reserved. Defaults to one below MinEpsilon. Can be defined explicitly to a smaller value to open the reserved-but-not-epsilon region. A non-integral key has no default and must be spelled explicitly.
EpsilonIsGreatestWhether no key sorts above MinEpsilon. Defaults to true only for an integral key whose MinEpsilon is its largest value.
