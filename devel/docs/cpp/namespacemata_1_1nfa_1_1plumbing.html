◆ get_words_lazy_ptr()

utils::LazyWordGenerator * get_words_lazy_ptr ( const Nfa & aut,
const std::optional< size_t > max_length = std::nullopt )
inline

Same as Nfa::get_words_lazy(), but as a free function returning a heap-allocated wrapper instead of a std::generator.

Exists for callers that cannot drive a C++23 coroutine directly — namely the Python bindings, generated by Cython, which has no notion of C++23 coroutines/sentinels. Prefer Nfa::get_words_lazy() everywhere else.

Throws std::runtime_error when MATA_HAS_GENERATOR_SUPPORT is unset (i.e. the standard library does not implement std::generator — some, like Apple's system libc++, do not, even under -std=c++23).

Parameters
autAutomaton whose language is enumerated.
max_lengthMaximum length of words to be returned. Default: "no limit"; will keep yielding forever if the language is infinite.
Returns
A heap-allocated generator; the caller takes ownership and must delete it.

Compute intersection of two NFAs.

Both automata can contain ε-transitions. The product preserves the ε-transitions, i.e., for each each product state (s, t) withs -ε-> p, (s, t) -ε-> (p, t) is created, and vice versa.

Automata must share alphabets.

Parameters
[out]resThe resulting intersection NFA.
[in]lhsInput NFA.
[in]rhsInput NFA.
[in]first_epsilonsmallest epsilon.
[out]prod_mapMapping of pairs of the original states (lhs_state, rhs_state) to new product states (not used internally, allocated only when !=nullptr, expensive).
Returns
NFA as a product of NFAs lhs and rhs with ε-transitions preserved.

Reduce NFA using residual construction.

The residual construction of the residual automaton and the removal of the covering states is done after the final determinization.

Similar performance to reduce_residual_with(). The output is almost the same except the transitions: transitions may slightly differ, but the number of states is the same for both algorithm types.
