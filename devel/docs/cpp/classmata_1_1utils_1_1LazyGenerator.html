Detailed Description

template<class T>
class mata::utils::LazyGenerator< T >

Fallback declaration used when the standard library does not implement std::generator (notably Apple's system libc++, even under -std=c++23). The type stays declared so that the bindings-facing *_lazy_ptr() functions have the same signature on every platform; it is never instantiated, because those functions throw instead of constructing one.
