Detailed Description

template<typename D, typename P>
class mata::posts::KeyedAccess< D, P, std::index_sequence< 0 > >

Specialisation of KeyedAccess for arity 1.

Hand-written rather than the generic template: add has an append fast path (back().key() < symbol) that skips the search when a relation is built in sorted order, where insert_target searches first, and twice on a miss. Bodies in mata/core/delta.tpp.
