Detailed Description

Concrete NFA implementations of algorithms, such as complement, inclusion, or universality checking.

This is a separation of the implementation from the interface defined in mata::nfa.

Note
In mata::nfa interface, there are particular dispatch functions calling these function according to parameters provided by a user. E.g., we can call the following function: is_universal(nfa, alphabet, {{'algorithm', 'antichains'}}) to check for universality based on antichain-based algorithm.
