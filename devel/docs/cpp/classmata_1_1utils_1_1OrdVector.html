Detailed Description

template<class Key, class Allocator>
class mata::utils::OrdVector< Key, Allocator >

Implementation of a set using ordered vector.

This class implements the interface of a set (the same interface as std::set) using ordered vector as the underlying data structure. Replacing it with std::flat_set, or its merge and search with alternatives, was measured and rejected: see EXP-1 in docs/experiments/.

Template Parameters
KeyKey type: type of the elements contained in the container. Each element in a set is also its key.

Construct from any input range whose elements convert to Key. A forwarding reference keeps ranges with non-const begin() (e.g. a named std::views::filter result) usable; the elements are converted from the references the range yields, and a sentinel of a different type than the iterator is supported. bool set_union ( const OrdVector< Key, Allocator > & lhs,
const OrdVector< Key, Allocator > & rhs,
OrdVector< Key, Allocator > & result )
inlinestatic

Write the union of lhs and rhs into result.

result has to be empty: the elements are appended to it, and the return value counts them against lhs. Passing a cleared buffer instead of a fresh vector keeps its capacity across calls, which is what makes this overload worth having next to set_union(lhs, rhs).

Returns
true iff rhs has an element that is not in lhs.
