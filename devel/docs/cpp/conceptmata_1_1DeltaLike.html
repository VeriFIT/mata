Detailed Description

A concept for a transition relation an mata::AutomatonBase can be built on.

Exactly what the structural algorithms use: a graph over states, with no keys and no post. A relation built from mata::posts::Post satisfies it, but so does a plain adjacency list.

Note
One contract, deliberately whole so the errors are reported immediately, rather then at the calls inside functions that need them.
The largest State is reserved as "no state": a relation never holds it as a state, so it has at most that many states.
The automaton's states can outnumber the relation's: an initial or final state may have no transitions stored. The traversal members (for_each_successor(), successor_cursor(), has_self_loop()) are called for every state of the automaton, and have to treat such a state as one without transitions, rather than reject it.
