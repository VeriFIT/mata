Detailed Description

template<typename P, size_t Arity = P::key_arity>
class mata::posts::SuccessorCursor< P, Arity >

A generic resumable cursor over every target reachable from one state post.

Flattens the descent down the post chain into a single pointer sweep, so a position can be stored and continued later.

Template Parameters
PThe whole post chain, not one post of it.
