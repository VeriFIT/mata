Should be use anytime the automata have a specific names for the symbols.

◆ get_alphabet_symbols_ref()

const utils::OrdVector< Symbol > & get_alphabet_symbols_ref ( ) const

Get the symbols of the alphabet, as get_alphabet_symbols() does, without copying them.

The sorted symbols are kept between calls and rebuilt only after the set of symbols changes. The reference stays valid until the alphabet is modified, moved from, or destroyed. Concurrent calls are safe as long as no thread modifies the alphabet.

Returns
Sorted symbols of the alphabet.

◆ update_next_symbol_value()

void update_next_symbol_value ( Symbol value)

Update next symbol value when appropriate.

When the newly inserted value is larger or equal to the current next symbol value, update the next symbol value to a value one larger than the new value. Values EPSILON and above are ignored, so the next symbol value never wraps and never exceeds EPSILON.

Parameters
valueThe value of the newly added symbol.
