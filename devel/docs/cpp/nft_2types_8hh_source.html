72/**
73 * How @c compose() normalizes its result after the construction.
74 *
75 * Every mode keeps the relation and the level of every state; state numbering is not part of the contract, and
76 * neither is the placement of EPSILON, which @c are_equivalent() reads as a letter.
77 */
78enum class CompositionNormalization : std::uint8_t {
79 None, ///< Return the result as constructed (trimmed when the synchronization levels are projected out).
80 /// Rewrite only the states the fast composer generated itself (EPSILON padding, bridges over a replaced
81 /// synchronization, and waiting states): close the whole-round EPSILON runs through generated states with exactly
82 /// one incoming and one outgoing transition, outside EPSILON cycles and where the result does not grow, then
83 /// merge generated states of the same level with the same outgoing transitions. Near-linear in the generated
84 /// states and their transitions. The general composition generates no such states and is left as constructed.
85 GeneratedOnly,
86 /// @c GeneratedOnly, then the generic @c remove_epsilon() (with @c JumpMode::NoJump only, as it reads every
87 /// transition as one level long), @c Nft::trim() and simulation-based @c reduce(). Far more expensive than the
88 /// composition itself; only for callers who want the smallest result.
89 Full,
90 /// @c None: @c GeneratedOnly costs more in the composition than it saves in a following composition on the
91 /// transducers of string constraints, whose results it shrinks by a few percent.
92 Auto,
93 /// @c None, then trimmed, also when the synchronization levels are kept. The fast composer then builds the result
94 /// forward and from the final states (by composing the reverted operands) in turns with a growing state budget
95 /// and keeps whichever finishes first: on the transducers of string constraints, either direction can build tens
96 /// of times more states that the trim removes than the other. Under @c None and @c Auto it builds forward only,
97 /// which is cheaper when the forward direction wins, as it does on most compositions. Operands it reads through
98 /// the cursors of their jump transitions are composed forward only.
99 Trim
100};

119 /**
120 * @brief Ordering for Levels in NFTs where lower levels precede higher levels.
121 *
122 * That is, levels are ordered as follows: 0 < 1 < 2 < ... < num_of_levels-1.
123 */
124 static bool Minimal(const Level lhs, const Level rhs) { return std::less()(lhs, rhs); }
125 /**
126 * @brief Ordering for levels in NFTs where lower levels precede higher levels, except for 0 which is the
127 * highest level.
128 *
129 * That is, levels are ordered as follows: 1 < 2 < ... < num_of_levels-1 < 0.
130 * This ordering is used when handling intermediate states (with non-zero levels) in NFTs for determining the
131 * next lowest level of the next state.
132 */
133 static bool Next(const Level lhs, const Level rhs) {
134 if (lhs == 0) { return false; }
135 if (rhs == 0) { return true; }
136 return lhs < rhs;
137 }
