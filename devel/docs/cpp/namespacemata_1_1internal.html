◆ tarjan_scc_discover()

template<typename Delta, typename Callbacks>
void tarjan_scc_discover ( const Delta & delta,
const size_t num_of_states,
const utils::SparseSet< typename Delta::State > & initial_states,
Callbacks && callbacks )

Run the non-recursive Tarjan traversal over delta starting at initial_states.

The SCC callback receives its members in Tarjan-stack order (bottom to top, i.e., the reverse of the order in which they are popped) and the remaining Tarjan stack. Both spans are valid only for the duration of that callback. nullptr callbacks are skipped at compile time. The traversal stops when a state- or SCC-level callback returns true.
