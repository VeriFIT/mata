Concatenate two NFAs.

Connects lhs and rhs by adding ε-transitions from each final state of lhs to each initial state of rhs. The ε is set to epsilon. If use_epsilon is false, remove_epsilon(epsilon) is run on the result, so every transition over epsilon disappears, including the operands' own transitions labelled with that symbol. Operand transitions over any other symbol are preserved; in particular, with epsilon != EPSILON the operands' EPSILON transitions survive, which is not the case when epsilon == EPSILON.

Parameters
[in]lhsFirst automaton to concatenate.
[in]rhsSecond automaton to concatenate.
[in]epsilonSymbol used for the connecting transitions between lhs and rhs.
[in]use_epsilonWhether to keep the connecting epsilon transitions in the result.
[out]lhs_state_renamingMap mapping lhs states to result states. Filled only when requested; it describes the shift of the full concatenation even when the result is empty.
[out]rhs_state_renamingMap mapping rhs states to result states. Filled only when requested; it describes the shift of the full concatenation even when the result is empty.
Returns
Concatenated automaton.

Determinize automaton by the "Four Russians" subset construction.

This is the "Four Russians" technique of Arlazarov, Dinic, Kronrod and Faradzev (1970), applied lazily.

Gives the DFA of determinize_classical() up to the numbering of the states, usually much faster on large automata. The default algorithm of determinize(). The NFA states are cut into blocks, and the post of each combination of states of a block is computed once, when it first occurs, and kept in a table. The post of a macrostate is then a union over its blocks instead of its states.

With a reduction, it gives a smaller DFA for the same language, not always minimal. A reduction usually lowers the memory usage. Its effect on the time varies: inputs whose DFA shrinks a lot are much faster, others may be slower.

const Nfa dfa = algorithms::determinize_four_russians(aut);
const Nfa smaller = algorithms::determinize_four_russians(aut, {.reduction = DeterminizationReduction::Adaptive});

◆ identical_successor_classes()

std::vector< State > identical_successor_classes ( const Automaton & aut,
size_t num_of_states,
std::span< const Level > levels = {} )

Classes of states that have the same finality, the same level, and, over every symbol, successors in the same classes.

Starts from the identity and merges states with identical successors, then states whose successors became identical by the merge, until nothing merges. Every merge joins classes with the same successors, so the partition stays a bisimulation and the quotient keeps the forward simulation of every state. It is far cheaper than the simulation itself: the first pass hashes each state post once, and after it only the classes of the predecessors of the states of an absorbed class are hashed again. The classes are numbered in the order of their smallest states.

Parameters
[in]autAutomaton whose states to classify.
[in]num_of_statesNumber of states of aut.
[in]levelsLevel of each state of a transducer. States past its end, and all states of an NFA, for which it is empty, are on level 0.
Returns
The class of each state; the number of classes is one past the largest class.

Inclusion by bisimulation up to congruence (HKC), after F.

Bonchi and D. Pous, "Checking NFA equivalence with bisimulations up to congruence", POPL 2013.

Checks that the macrostates X ∪ Y and Y are equivalent for every pair of a macrostate X of smaller and Y of bigger reached over the same word, starting from the initial states. Unlike is_included_antichains(), which pairs single states of smaller with macrostates of bigger, it determinizes both automata on the fly. A pair is skipped when it lies in the congruence closure of the pairs stored before, which for this shape of pairs means that every state x of X lies in a stored pair whose macrostate of bigger is a subset of Y; a stored pair all of whose states of smaller are covered this way by pairs with smaller macrostates is not expanded either. EPSILON is an ordinary symbol here.

Parameters
[in]smallerAutomaton which language should be included in the bigger one
[in]biggerAutomaton which language should include the smaller one
[in]alphabetAlphabet of both automata (not needed by the algorithm)
[out]cexA word of smaller rejected by bigger, with an accepting run of smaller over it, when the inclusion does not hold; cleared otherwise.
Returns
True if the language of smaller is included in the language of bigger.

◆ macrostate_signature()

uint64_t macrostate_signature ( const StateSet & macrostate)
inline

Signature of a macrostate: the OR of 1 << (q % 64) over its states q.

A superset can only have more bits set, so a bit present in macrostate_signature(a) and absent from macrostate_signature(b) exhibits a state of a that is missing from b and proves a ⊄ b. The converse does not hold: states that are congruent modulo 64 share a bit, so equal signatures prove nothing. The filter therefore only ever rejects, which is what the antichain subsumption tests need to stay sound.

Nfa minimize_auto ( const Nfa & aut)

Minimization that picks the algorithm from the shape of the input.

Uses minimize_hopcroft_nondet(): determinizes aut when it is not deterministic already, trims it, and runs Hopcroft minimization on the result. Brzozowski minimization is never picked: it determinizes twice, so it can blow up exponentially even on an input that is already a trimmed DFA, where Hopcroft is O(a*n*log(n)). ◆ minimize_hopcroft()

Nfa minimize_hopcroft ( const Nfa & dfa_trimmed)

Hopcroft minimization of automata.

Based on the algorithm from the paper: "Efficient Minimization of DFAs With Partial Transition Functions" by Antti Valmari and Petri Lehtinen. The algorithm works in O(a*n*log(n)) time and O(m+n+a) space, where: n is the number of states, a is the size of the alphabet, and m is the number of transitions. [https://dl.acm.org/doi/10.1016/j.ipl.2011.12.004]

Parameters
[in]dfa_trimmedDeterministic automaton without useless states, with no empty symbol posts. Trim it before calling this function and drop empty posts from the delta first: an empty post is not a transition, but the core validates and refines posts as stored, so it cannot be accepted. Skipping the trimming is not an error, it only costs minimality.
Exceptions
std::invalid_argumentIf dfa_trimmed has a transition and is not deterministic, or has several initial states. A transition-free automaton with at most one initial state is returned without refinement.
Returns
Minimized deterministic automaton, refined from dfa_trimmed. A transition-free automaton without an initial state is returned as it is, with no initial state: such a result is neither deterministic nor minimal by Nfa::is_deterministic() / Nfa::is_minimal(). Callers that need the canonical one-state empty-language DFA should use the public mata::nfa::minimize() dispatcher instead.

Quotient an NFA, or a successor-closed part of it, by its forward simulation.

Each class of states equivalent under sim_relation becomes one state; its transitions are those of the class representative, without targets simulated by another target over the same symbol. With states set, only those states are kept and the representative of a class is its smallest kept state. Since forward simulation does not depend on the initial states, one relation then serves every part reachable from a single state.

[out]state_renamingMap mapping the kept states to the reduced states, if not nullptr.

Reduce NFA to an NFA with the minimum number of states using an external QBF solver.

Experimental. The same search as reduce_sat() with type "nfa", but the sample words that the NFA has to reject are encoded with universally quantified runs instead of the reachable states of their prefixes.

Parameters

[in]solverCommand running a QBF solver, given as for reduce_sat(). The solver is given a QDIMACS file as its last argument and has to print the result and the values of the outermost existential variables in the QDIMACS output format ("s cnf 1 ..." or "s cnf 0 ..." and "V" lines). If empty, the value of the environment variable MATA_QBF_SOLVER is used and, if that is not set, the first of depqbf and caqe found in PATH, run with --qdo. A command whose executable is named exactly depqbf (whatever its directory) is also run with --no-dynamic-nenofex when its --help lists the option: DepQBF built with Nenofex prints the values of the variables only with it, while older versions reject it. The probe runs the executable alone, and a probe killed by a signal leaves the command unchanged. A DepQBF reached under another name (e.g. a depqbf-6 symlink or a wrapper script) is not probed: pass --no-dynamic-nenofex in solver when that version needs it.
[in]epsilonWhether to treat EPSILON as an ordinary letter ("letter", default) or remove it first as the empty word ("empty").
Returns
An NFA equivalent to nfa with the minimum number of states.

Nfa reduce_sat ( const Nfa & nfa,
const std::string & type = "nfa",
const std::string & solver = "",
const std::string & epsilon = "letter" )

Reduce NFA to an automaton with the minimum number of states using an external SAT solver.

Experimental. A counterexample-guided search: for k = 1, 2, ..., a SAT solver looks for an automaton with k states consistent with a set of sample words, the candidate is checked for equivalence with nfa, and a distinguishing word is added to the samples until the candidate is equivalent or no k-state automaton exists. The search is exponential in the worst case and is practical only for languages whose minimal automata have about ten states.

By default, an EPSILON transition is treated as a transition over an ordinary letter, as in the other reduction algorithms. Set epsilon to "empty" to run remove_epsilon() on the input first instead. The result uses the symbols and the alphabet of nfa.

Parameters
[in]nfaNFA to reduce.
[in]typeKind of the resulting automaton (values: "nfa", "dfa"):
  • "nfa": an NFA with the minimum number of states. It never has more states than nfa reduced by simulation.
  • "dfa": a deterministic (not necessarily complete) automaton with the minimum number of states.
[in]solverCommand running a SAT solver, as the solver's executable followed by its arguments separated by spaces. Parts containing spaces can be enclosed in single or double quotes; the command is not interpreted by a shell otherwise. The solver is given a DIMACS CNF file as its last argument and has to print the result in the format of the SAT competitions, that is, an "s SATISFIABLE" or "s UNSATISFIABLE" line and the model on "v" lines. If empty, the value of the environment variable MATA_SAT_SOLVER is used and, if that is not set, the first of cadical, kissat, cryptominisat5 and picosat found in PATH.
[in]epsilonWhether to treat EPSILON as an ordinary letter ("letter", default) or remove it first as the empty word ("empty").
Returns
An automaton equivalent to nfa with the minimum number of states of the given type.
Exceptions
ExternalSolverNotFoundIf no SAT solver can be found or run.
std::runtime_errorIf epsilon has an invalid value, the solver fails, or its output cannot be understood.
