Detailed Description

Allocator of the heap blocks of Delta: the symbol posts of a state post and the spilled target sets.

The backend is std (global operator new) or pool (thread-local bump chunks with size-class free lists). The environment variable MATA_DELTA_ALLOCATOR selects it; when it is unset or empty, the CMake option of the same name chose the default when libmata was built. The selection is read on the first allocation and fixed for the rest of the process, so every block is released by the backend that allocated it. The backend lives out of line, so header code inlined into a consumer and code inside libmata always pair the same allocation and release.
