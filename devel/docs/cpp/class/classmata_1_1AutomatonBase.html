Class mata::AutomatonBase¶

template<DeltaLike D>
class AutomatonBase¶

A class representing the structural part of an automaton.

Every operation defined here is a pass over delta, initial and final.

See also

mata::DeltaLike for what D must provide.

Note

A data-owning mixin, not a polymorphic base: it owns delta, initial and final, and has no virtual functions. The members that need their most-derived type take an explicit object parameter (deducing this) instead.

Note

D needs no keys: every operation here follows successors only, so the relation may be a plain graph.

Note

The largest State is reserved as “no state”, for initial and final as much as for delta: the algorithms count states in State and use the largest one as a marker.

Template Parameters:

D – The transition relation. Every other type is read off D rather than passed alongside it, so the two cannot disagree.

template<AutomatonWithRuns Self>
bool is_lang_empty(typename Self::Run *cex) const¶

Is the accepted language (or relation) empty, with a counter-example?

Note

Only for an automaton that has runs: the run type comes from Self.

Note

Unifying the two searches – having the Tarjan search emit a witness on demand – would save a traversal on the counter-example path, which is_included() and is_universal() take whenever the caller wants one. It would also stop the witness being shortest, and callers do depend on which one comes back (see the exact-word check in the “mata::nfa::Nfa::get_word()” tests). Worth doing only together with a decision about that.

Parameters:

cex – [out] Counter-example run, filled when an accepting path exists. With nullptr, none is built.

Returns:

true iff no accepting path exists.

bool is_acyclic() const¶

Is the part of the automaton graph reachable from the initial states acyclic?

A cycle no initial state reaches does not count.

Returns:

true iff no cycle is reachable from an initial state.

bool has_no_accepting_path() const¶

Is no final state reachable from any initial state?

A plain breadth-first search over a visited bit vector that stops at the first final state. This is a pure graph property; whether it coincides with the emptiness of the accepted language (or relation) is a fact about the concrete automaton class.

Returns:

true <-> no accepting path exists.

template<typename Self>
bool is_identical(const Self &other) const¶

Check if this is structuralry identical to other.

Compares only delta, initial and final. This is exact structural equality, including state numbering (so even stronger than isomorphism), essentially only useful for testing purposes.

Note

Templated on Self (deducing this) so that only same-type comparisons compile.

Parameters:

other – [in] The other automaton to compare with.

Returns:

true iff the structural parts of this and other are identical.

template<typename Self>
Self &trim(StateRenaming *state_renaming = nullptr)¶

Remove unreachable and non-terminating states in-place.

Remaining states are renumbered densely in ascending order.

Note

A state is reachable when the state is the endpoint of a path starting from an initial state. A state is terminating when the state is the starting point of a path ending in a final state.

Note

Reached only through a leaf’s own one-line trim(), on *this, so an lvalue Self suffices here.

Parameters:

state_renaming – [out] Mapping of trimmed states to new states.

Returns:

this after trimming.
