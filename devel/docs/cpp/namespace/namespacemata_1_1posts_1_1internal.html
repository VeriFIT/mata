#include <post.hh>

The body of mata::posts::PostEntry.

PostEntry re-exposes symbol and targets only where those names are accurate: when the nested type is the target set. Everywhere else an entry is read through key() and nested(). The members that treat the nested type as the target set are constrained to that case the same way, so above it they are absent rather than quietly answering about the nested post.

Subclassed by PostEntry< Symbol, SmallStateSet >, PostEntry< K, N >
