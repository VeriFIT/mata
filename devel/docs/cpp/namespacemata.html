Detailed Description

Main namespace including structs and algorithms for all automata.

In particular, this includes:

  1. Alphabets,
  2. Formula graphs and nodes,
  3. Mintermization,
  4. Closed sets.

◆ DeltaBuilder

using DeltaBuilder = posts::DeltaBuilder<mata::Delta>

Builds a Delta in its final form from transitions given in order: sources, then symbols of a source, then targets of a symbol, each strictly increasing.

The builder installs finished posts directly;.

Every symbol post is created once with exact capacity, instead of being grown target by target.

The builder is the generic posts::DeltaBuilder over this relation;

◆ EpsilonClosureOpt

enum class EpsilonClosureOpt : std::uint8_t
strong

Where an epsilon closure is applied around a transition step.

The values are bit flags, so BeforeAndAfter must be tested with closes_before() and closes_after() rather than compared for equality. For 0 -ε-> 1 -a-> 2 -ε-> 3 and the step over a from {0}:

Option Applied Result
None post(S) {}
Before post(closure(S)) {2}
After closure(post(S)) {}
BeforeAndAfter closure(post(closure(S))) {2,3}
Enumerator
None 

No epsilon closure.

Before 

Epsilon closure before the transition.

After 

Epsilon closure after the transition.

BeforeAndAfter 

Epsilon closure before and after the transition.

◆ quote_symbol_name()

std::string quote_symbol_name ( const std::string_view name)

Returns name written as a single token of the .mata format.

Quotes the name when it is empty, contains white space, a quote, or a character the reader treats specially ("#@%()!&|\\"), writing an inner @c " as ", the only escape the reader knows. A name ending in \ cannot be quoted this way, because the reader reads the closing " as an escaped quote; such a name never reads back to the same symbol.
