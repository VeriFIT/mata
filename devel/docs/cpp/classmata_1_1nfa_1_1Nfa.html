Add a new transition from source to target labeled by the symbol named symbol_name.

Convenience wrapper around delta.add(), translating symbol_name to a Symbol via the resolved alphabet instead of requiring the caller to call alphabet->translate_symb() themselves, i.e., aut.add_transition(source, "my_symbol", target) instead of aut.delta.add(source, aut.alphabet->translate_symb("my_symbol"), target).

Parameters
[in]sourceSource state of the new transition.
[in]symbol_nameName of the symbol labeling the new transition, translated via the resolved alphabet.
[in]targetTarget state of the new transition.
[in]alphabetAlphabet to translate symbol_name with, taking precedence over this->alphabet when non-null.
Exceptions
std::runtime_errorIf neither alphabet nor this->alphabet is set.

◆ get_word_from_complement()

std::optional< Word > get_word_from_complement ( const Alphabet * alphabet = nullptr) const

Get any arbitrary accepted word in the language of the complement of the automaton.

The automaton is lazily determinized and made complete. The algorithm returns an arbitrary word from the complemented NFA constructed until the first macrostate without any final states in the original automaton is encountered.

Parameters
[in]alphabetAlphabet to use for computing the complement. If nullptr, uses this->alphabet when defined, otherwise uses this->delta.get_used_symbols().

Transitions over symbols outside of the chosen alphabet are ignored; the automaton is complemented only with respect to the symbols of alphabet and the returned word never contains any other symbol.

Precondition
The automaton does not contain any epsilon transitions. TODO: Support lazy epsilon closure?
Returns
An arbitrary word from the complemented automaton, or std::nullopt if the automaton is universal on the chosen set of symbols for the complement.

◆ get_words()

std::set< Word > get_words ( size_t max_length) const

Get the set of all words in the language of the automaton whose length is <= max_length.

If you have an automaton with finite language (can be checked using is_acyclic()), you can get all words by calling get_words(aut.num_of_states())

The search goes over words, not over paths: the states reachable by a word are kept together as one macrostate, so the work is bounded by the number of distinct words of length <= max_length that have a run in the automaton, no matter how many accepting paths each of them has.

◆ print_to_regex() [2/3]

std::string print_to_regex ( RegexPrintMode mode = RegexPrintMode::Fast,
const Alphabet * alphabet = nullptr ) const

Prints the language of the automaton as a regular expression.

The automaton is converted by state elimination, see src/nfa/regex-writer.cc. mode chooses what the conversion optimizes for:

  • RegexPrintMode::Fast converts as fast as possible, for a regex read by a program.
  • RegexPrintMode::Readable looks for a short, legible regex, for a regex read by a human: it converts several automata of the same language (the reduced one, the minimal deterministic one, and the minimal one deterministic backwards) in several elimination orders, simplifies the regexes algebraically, and prints the shortest one, which is never longer than the regex of RegexPrintMode::Fast. Running these additional conversions takes considerably longer than RegexPrintMode::Fast.

The length of the regex is exponential in the number of states in the worst case, in both modes.

The regex is written in the syntax mata::nfa::builder::create_from_regex() reads (RE2), restricted to characters, escapes ('\n', '\x41', '\x{17F}'), character classes ('[a-c]'), groups, '|', '*', '+', '?', and counted repetitions ('{2}', '{2,}', '{2,5}'). The empty word alone is '()', and the empty language is the empty character class '[^\s\S]'.

A symbol is the Unicode scalar value of its value, so it has to be at most 0x10FFFF and must not be in the surrogate range 0xD800 to 0xDFFF. With symbols up to 0xFF, reading the regex back gives the same language; with larger ones, reading it back with Encoding::Utf8 gives the language encoded in UTF-8. With an alphabet, a symbol is the character its name consists of instead. EPSILON is the empty word.

Parameters
[in]modeWhat to optimize the conversion for.
[in]alphabetIf specified, translates the symbols to their symbol names in the alphabet. Otherwise, the alphabet of the automaton is used, if it has one.
Returns
The regular expression.
Exceptions
std::invalid_argumentIf a symbol is larger than 0x10FFFF or a surrogate, or its name in the alphabet is not a single character encoded in UTF-8.

Nfa & unite_nondet_with ( Nfa && nfa) &

In-place nondeterministic union of this with nfa, consuming nfa.

Does not add epsilon transitions, just unites initial and final states. The state posts of nfa are moved into this, so no deep copy of the operand occurs. If this and nfa are aliased (which should not normally happen with rvalues), a controlled snapshot is taken and the operation falls back to the lvalue path. nfa is left valid but empty after the operation.

Returns
this after uniting with nfa.
