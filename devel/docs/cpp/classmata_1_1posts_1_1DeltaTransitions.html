Detailed Description

template<typename D>
class mata::posts::DeltaTransitions< D >

Iterator over the transitions of a relation.

A non-owning view: it must not outlive the relation, and changing the relation invalidates its iterators. Transitions come by ascending source, then in the order of the relation's CursorType. Each is built on the fly with TransitionTraits::make, so *it refers to a value held by the iterator and is invalidated by ++it.
