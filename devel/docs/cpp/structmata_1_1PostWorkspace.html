Detailed Description

Reusable buffers of post() and epsilon_closure(), so that a loop of steps allocates once.

A call writes all of its buffers, so one workspace serves one call at a time. Concurrent calls, even const queries of the same delta, each need their own; in particular a workspace must never be a function-local static.
