Detailed Description

template<typename E, typename R = ReservedKeys<typename E::Key>, typename A = std::allocator<E>>
class mata::posts::Post< E, R, A >

One post of the relation: an ordered map from a key to the post nested under it.

An ordered vector of E kept sorted by key, which is what every lookup binary-searches on. Every step of a chain is one of these. A relation of key_arity n is n of them deep, ending in a mata::posts::TargetSetLike.

For relation with key_arity 1, the top level post uses a name alias StatePost, and the next level down uses SymbolPost.

Template Parameters
EThe entry type: one key plus what is nested under it.
RWhere this post's ordinary keys stop.
See also
mata::ReservedKeys.
Template Parameters
AThe allocator of the entries. mata::StatePost uses mata::utils::DeltaAllocator.
See also
mata::posts::PostLike.
