Class mata::FormulaNode¶

class FormulaNode¶

A node of graph representing transition formula.

A node could be operator (!,&,|) or operand (symbol, state, node). Each node has its raw name as written in the input, its name (the raw name without the type marker, the initial character, under the marked naming), and information about its type.

Type type = {}¶

Define whether a node is operand or operator.

std::string_view raw = {}¶

Raw name of node as it was specified in input text, i.e., including type marker.

The name is not owned: it has to point into the name storage of the automaton the node belongs to (IntermediateAut::name_store or IntermediateAut::section_names) or into a literal, so that it lives for as long as the node does.
