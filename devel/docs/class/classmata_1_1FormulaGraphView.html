Class mata::FormulaGraphView¶

class FormulaGraphView¶

A subtree of a FormulaGraph: a view, valid while the graph it points into lives and is not modified.

A view of an empty graph is a single node of the type FormulaNode::Type::Unknown without children.

Public Functions

constexpr FormulaGraphView() = default¶

A view of an empty graph.

inline FormulaGraphView(const FormulaGraph &graph)¶

The view of the whole graph.

inline std::span<const FormulaGraphEntry> entries() const¶

The nodes of the subtree in postfix order: the subtrees of the children of a node come right before the node.
