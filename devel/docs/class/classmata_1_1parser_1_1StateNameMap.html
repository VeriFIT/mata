Class mata::parser::StateNameMap¶

class StateNameMap¶

The map from state names to states of the readers, which behaves as the std::unordered_map it is built from and turns into, but finds the names of printed automata, a fixed prefix followed by a number, in a vector.

Public Functions

Parameters:

  • names – The initial names.

  • max_number – The largest number kept in the vector, which bounds its size.
