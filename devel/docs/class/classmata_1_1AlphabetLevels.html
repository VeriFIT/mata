Class mata::AlphabetLevels¶

class AlphabetLevels

Per-level alphabets for transducer-like automata.

Standalone (does NOT inherit from Alphabet) wrapper holding a vector of std::shared_ptr<Alphabet>, one per level. Operates in one of two modes (see Mode):

  • Global — a single shared alphabet (typically stored in alphabets[0]) applies to every level. The level argument is ignored.

  • MultiLevel — distinct per-level alphabets. The level argument is required and indexes alphabets.

The underlying Alphabet objects are held via std::shared_ptr and can be shared between multiple AlphabetLevels instances (and other automata).

Raw slot access (mode-agnostic).

Bounds-checked access to a raw slot by its index in the underlying vector, ignoring mode.

Unlike for_level, a null entry is returned as-is instead of throwing; only an out-of-range index throws.

See also

std::vector::at.

Memberwise comparison of mode and the stored alphabet slots. Slots are std::shared_ptr<Alphabet> and are compared by the pointee’s identity (i.e., whether both slots point to the same underlying Alphabet object), not by the alphabets’ contents, since Alphabet does not support value equality.

inline void set_global_mode(Level level_for_kept_alphabet = 0)

Switch to Global mode, keeping only the alphabet at level_for_kept_alphabet as the single shared alphabet.

Any other stored alphabets are dropped from AlphabetLevels (the Alphabet objects themselves survive if still referenced elsewhere, since they are held via shared_ptr). Unlike for_level, this never throws due to a missing alphabet: switching an empty instance to Global just leaves it empty.

Parameters:

level_for_kept_alphabet – [in] Level whose alphabet to keep. Ignored when no alphabet is currently stored.

Throws:

std::out_of_range – If level_for_kept_alphabet is out of range and at least one alphabet is stored.

inline void set_global_mode(std::shared_ptr<Alphabet> alphabet)

Switch to Global mode, using alphabet as the new single shared alphabet.

Replaces any previously stored alphabets regardless of how many there were. AlphabetLevels takes shared ownership of alphabet (via std::shared_ptr); it may still be shared with other owners.

Parameters:

alphabet – [in] The alphabet to use for every level.

inline void set_multi_level_mode() noexcept

Switch to MultiLevel mode.

Always safe: MultiLevel places no constraint on the number of stored alphabets. Existing alphabets are kept as-is, now indexed by level (e.g., a single alphabet from Global mode becomes level 0’s alphabet).

bool empty(std::optional<Level> level = std::nullopt) const

Check whether the alphabet for the given level is empty.

In Global mode, always checks alphabets[0] (level argument is ignored). In MultiLevel mode, checks alphabets[level] when level has a value, or returns true iff every underlying alphabet is empty when level is std::nullopt.

void clear(std::optional<Level> level = std::nullopt)

Clear the alphabet for the given level.

In Global mode, always clears alphabets[0] (level argument is ignored, calling clear repeatedly is idempotent on the same alphabet). In MultiLevel mode, clears alphabets[level] when level has a value, or clears every underlying alphabet when level is std::nullopt.

const std::shared_ptr<Alphabet> &for_level(std::optional<Level> level = std::nullopt) const

Get the alphabet assigned to a specific level.

Validated accessor for the internal vector of std::shared_ptr<Alphabet>.

  • In Global mode, alphabets[0] is returned regardless of level.

  • In MultiLevel mode, level must have a value and be a valid index; the corresponding entry must be non-null.

The stored shared ownership token is handed out (never null on return; missing alphabets throw instead), so that callers which need to keep the alphabet alive beyond the lifetime of this AlphabetLevels (or beyond the next mutation of its slots) can simply copy the returned std::shared_ptr. Callers which only read the alphabet should dereference the returned reference directly (*levels.for_level(level)), which costs no reference-count update. The non-const overload additionally allows replacing the alphabet stored for level.

Parameters:

level – [in] Level whose alphabet should be returned (required in MultiLevel mode).

Throws:

std::runtime_error – If level is missing in MultiLevel mode, out of range, or the entry is null.

Returns:

Non-null std::shared_ptr to the alphabet assigned to level.

Public Members

std::vector<std::shared_ptr<Alphabet>> alphabets_ = {}

Per-level alphabets.

In Global mode, only alphabets[0] is used. In MultiLevel mode, indexed by level. Private so that the Global invariant (exactly one alphabet) can be enforced by the build-up methods below; use for_level (or operator[]) for validated read/write access, at for raw slot access, or the vector-like methods to build up a MultiLevel instance.

Warning

Modifying directly may break the class invariants.

Mode mode_ = {Mode::MultiLevel}

Operating mode.

Defaults to MultiLevel.

Private so switching to Global can be rejected while more than one alphabet is stored (see set_global_mode).

Warning

Modifying directly may break the class invariants.
