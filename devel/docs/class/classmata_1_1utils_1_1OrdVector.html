Class mata::utils::OrdVector¶

template<class Key>
class OrdVector¶

Implementation of a set using ordered vector.

This class implements the interface of a set (the same interface as std::set) using ordered vector as the underlying data structure.

Template Parameters:

Key – Key type: type of the elements contained in the container. Each element in a set is also its key.

inline std::pair<iterator, bool> insert(Key &&x)¶

Insert x, moving from it when it is not present yet.

Without this overload, an insert(std::move(x)) call binds to insert(const Key&) and copies x, which matters for keys that own memory (e.g. SymbolPost).

static inline bool set_union(const OrdVector &lhs, const OrdVector &rhs, OrdVector &result)¶

Write the union of lhs and rhs into result.

result has to be empty: the elements are appended to it, and the return value counts them against lhs. Passing a cleared buffer instead of a fresh vector keeps its capacity across calls, which is what makes this overload worth having next to set_union(lhs, rhs).

Returns:

true iff rhs has an element that is not in lhs.
