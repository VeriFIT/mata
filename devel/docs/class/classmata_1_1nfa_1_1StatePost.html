Class mata::nfa::StatePost¶

class StatePost : private OrdVector<SymbolPost>¶

A data structure representing possible transitions over different symbols from a source state.

It is an ordered vector containing possible SymbolPost (i.e., pair of symbol and target states). SymbolPosts in the vector are ordered by symbols in SymbolPosts.

Public Functions

inline bool operator==(const StatePost &other) const¶

Two posts are equal when they hold the same symbols with the same targets.

Not defaulted: a defaulted operator== compares the OrdVector base element by element, and SymbolPost::operator== only looks at the symbol, so posts with different targets compared equal.

static inline bool set_union(const OrdVector &lhs, const OrdVector &rhs, OrdVector &result)¶

Write the union of lhs and rhs into result.

result has to be empty: the elements are appended to it, and the return value counts them against lhs. Passing a cleared buffer instead of a fresh vector keeps its capacity across calls, which is what makes this overload worth having next to set_union(lhs, rhs).

Returns:

true iff rhs has an element that is not in lhs.
